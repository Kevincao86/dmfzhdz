# 灵祺 · 网页版商业计划书

基于 `调研报告/Lingqi-Seed-Funding-BP/` 与 `docs/BP-灵祺-种子轮500万-杭甬温.md` 制作的交互式种子轮路演页。

**数据口径（2026-08 对齐）：** 对外默认 **Base 轨**（M12 1,500–3,000 店 / MRR≥100万；M24 8,000–15,000 店 / MRR≥500万）；订阅锚点约 ¥168/月。

## 本地预览

```bash
cd 商业BP
python3 -m http.server 8765
# 浏览器打开 http://localhost:8765
```

或使用任意静态服务器（Live Server、`npx serve` 等）。

## 交互功能

- 粒子背景 + 鼠标光晕
- 数字滚动动画（融资 500 万、灰测 3 家等）
- 市场规模 **增长曲线描绘** + 柱状动画
- 痛点卡片翻转（正反面，按钮底对齐）
- 双引擎 / 产品矩阵 Tab 切换
- 杭甬温城市切换 + 时间线
- 融资用途点击高亮
- 竞争雷达图（滑块可调）
- **投资人模式** 高亮关键指标
- **路演播放** 自动轮播章节
- 明暗主题切换
- **预约路演** 弹窗（创始人 + 微信二维码）
- 团队优势 / ROI 预估 / 交付 KPI（参考墨典AI智慧店长商业BP）

参考材料：`../墨典AI智慧店长商业BP.pdf`（项目上级目录）

## 部署

### 方式 A：随商家 ERP 一起上线（推荐）

`main` 分支推送后，Vercel 构建会把本目录复制到 `dist/bp/`：

- 路径示例：`https://<你的-vercel-域名>/bp/` 或 `https://cs.mofangdianai.com/bp/`

### 方式 B：独立 Vercel 项目

在 Vercel 新建项目，**Root Directory** 设为 `商业BP`，使用本目录 `vercel.json`（纯静态，无需 build）。

### 方式 C：OSS

将整个 `商业BP` 目录上传至 OSS 静态网站即可。
