# 备案过渡期：微信云开发代理 ECS

`mofangdian.com` 备案审核期间，手机直连 `mofangdianai.com` 会被微信 Cronet reset（-101）。  
**临时方案**：小程序 → **云函数 `mpErpProxy`** → ECS `https://mofangdianai.com/erp-api`（数据仍在你的 ECS，不是 Vercel/Supabase 云）。

备案通过后：改用 `utils/config.release.after-beian.example.js` 直连 `https://mofangdian.com/erp-api`。

---

## 一、开通云开发（约 10 分钟）

1. 微信开发者工具打开本小程序项目  
2. 顶部 **云开发** → 开通（按量付费即可，登录/大厅流量很小）  
3. 记下 **环境 ID**（如 `cloud1-2gxxxxx`）  
4. 编辑 `utils/config.release.js`：

```javascript
MP_CLOUD_ENV: 'cloud1-你的环境ID',
```

5. `app.js` 会自动 `wx.cloud.init`（已写好）

---

## 二、部署云函数

1. 在目录树找到 `cloudfunctions/mpErpProxy`  
2. 右键 → **上传并部署：云端安装依赖**  
3. 云开发控制台 → **设置 → 环境变量**，新增：

| 变量名 | 值 |
|--------|-----|
| `ECS_ERP_ORIGIN` | `https://mofangdianai.com/erp-api` |

4. 云开发 → 云函数 → `mpErpProxy` → 测试：

```json
{ "method": "GET", "path": "/api/mp-cronet-ping" }
```

应返回 `ok: true`。

---

## 三、上传体验版

1. 确认 `utils/mpBuild.js` 为 **`mp-20260606-cloud-proxy`**  
2. 上传体验版  
3. **删除手机小程序** → 重扫  
4. 登录页应显示 **`ECS 可达`**（经云代理）

> 过渡期 **可不配置** request 合法域名 `mofangdianai.com`（API 走云函数）。  
> 若仍有直连请求，可暂时保留合法域名配置。

---

## 四、备案通过后切换到 mofangdian.com

1. DNS：`mofangdian.com` A 记录 → 与现 ECS 同 IP  
2. ECS 签发证书并 Nginx 增加 `server_name mofangdian.com`（`bash scripts/ecs-mp-add-domain.sh mofangdian.com`）  
3. 将 `config.release.after-beian.example.js` 内容复制到 `config.release.js`：

```javascript
MP_USE_CLOUD_PROXY: false,
MERCHANT_API_BASE_URL: 'https://mofangdian.com/erp-api',
```

4. 微信后台 request 合法域名改为 **`https://mofangdian.com`**  
5. 重新上传体验版

---

## 费用说明

云开发按调用次数/资源计费；仅作 API 转发时通常 **每月几元级**（以微信账单为准）。
