# 墨典官网

宁波墨典网络科技有限公司官方网站（静态单页）。

## 本地预览

```bash
cd web版/modian-official
npm run dev
# 浏览器打开 http://127.0.0.1:5177
```

或直接用任意静态服务器打开本目录的 `index.html`。

## 结构

- `index.html` — 页面结构与文案
- `assets/css/main.css` — 视觉与响应式
- `assets/js/main.js` — 粒子网格、滚动显现、表单 mailto

## 联系信息

表单默认发送至 `hello@modian.ai`。上线前请替换为真实邮箱 / 电话 / 微信号。
