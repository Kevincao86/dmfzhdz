# 灵祺 ERP · 快手团购绑定说明书

本文说明如何在 **灵祺 AI 智能 ERP** 中对接 [快手生活服务开放平台](https://open.kwailocallife.com/)（goodlife 协议，与抖音来客接口结构一致），实现与 **抖音来客** 相同的绑定、门店、商品、首页看板与财务对账能力。

---

## 一、适用对象

- 已在快手本地生活/团购经营、并开通开放平台应用的商家或服务商。
- 需要在 ERP 内统一管理 **快手团购** 与抖音、美团等平台数据的运营/财务人员。

---

## 二、绑定前准备

| 项目 | 说明 |
|------|------|
| App ID / App Secret | 快手生活服务开放平台 → 应用管理 |
| 商户 account_id | 快手商家账户 ID，绑定校验与门店查询必填 |
| 能力权限 | 至少开通门店查询 `goodlife.v1.shop.poi.query`、类目 `goodlife.shop.query.category`、商品与订单相关能力 |
| 出口 IP 白名单 | 生产环境需将服务器出口 IP 加入开放平台白名单；Vercel 建议配置固定 EIP 反代 |

官方 API 文档示例（经营类目）：

https://open.kwailocallife.com/docs/api?apiName=goodlife.shop.query.category&version=1

门店 POI 查询：

https://open.kwailocallife.com/docs/api?apiName=goodlife.v1.shop.poi.query&version=1

## 三、开放平台配置步骤

### 1. 创建/选择应用

1. 登录 https://open.kwailocallife.com/
2. 进入 **应用管理**，创建自研应用或使用已有应用。
3. 记录 **App ID**、**App Secret**。

### 2. 申请 goodlife 能力

在应用「接口权限」中申请（名称以控制台为准）：

- 门店：`goodlife.v1.shop.poi.query`（门店列表）
- 类目：`goodlife.shop.query.category`（发品选类）
- 商品：线上/草稿查询、保存、上下架等（与抖音 goodlife 路径一致）
- 订单/对账：`goodlife/v1/trade/order/query` 等

### 3. 配置 IP 白名单

1. 在开放平台填写服务器 **出口公网 IP**。
2. 若部署在 Vercel，请使用 **华为云/阿里云 EIP + Nginx 反代** 固定出口，并在 Vercel 环境变量中设置：

```bash
KUAISHOU_OPENAPI_BASE_URL=https://你的反代域名或EIP路径
MERCHANT_KUAISHOU_SESSION_SECRET=请使用32字节以上随机字符串
```

可选（OAuth 与中继分离时）：

```bash
KUAISHOU_OPENAPI_OAUTH_BASE_URL=https://open.kwailocallife.com
```

自签证书反代时可临时设置（不推荐长期使用）：

```bash
KUAISHOU_OPENAPI_RELAY_TLS_INSECURE=1
```

## 四、灵祺 ERP 内绑定

1. 登录 ERP → **系统设置** → **商家版后台** → **团购平台** → **快手团购**。
2. 点击 **绑定**，填写：
   - **App ID**（client_key）
   - **App Secret**（client_secret）
   - **商户 ID**（account_id）
3. 点击 **确认绑定**。系统将：
   - 调用 `POST /oauth/client_token/` 获取 access_token
   - 调用 `GET /goodlife/v1/shop/poi/query/` 校验门店权限
   - 生成本地加密会话（生产环境写入 `MERCHANT_KUAISHOU_SESSION_SECRET` 密封凭证）
4. 绑定成功后，本页展示 **门店列表**；支持多账号切换（与抖音来客相同，同步至 Supabase `tenant_merchant_bindings`，provider=`kuaishou`）。

### 绑定失败常见原因

| 现象 | 处理 |
|------|------|
| IP 不在白名单 | 检查反代出口 IP 是否已填入快手开放平台 |
| 能力未开通 | 在开放平台申请 goodlife 门店/商品/订单能力 |
| account_id 错误 | 核对商家后台商户 ID |
| 请求过于频繁 | 等待 1～2 分钟后重试 |

## 五、绑定后可用的 ERP 功能

与 **抖音来客** 对齐：

| 模块 | 说明 |
|------|------|
| 店铺信息 | 门店列表、详情、装修（经 `/api/merchant/kuaishou/stores` 等） |
| 商品管理 | 类目、模板、发品、上下架、同步（goodlife 商品 API） |
| 首页看板 | 成交/核销趋势（`/api/meoo-merchant-dashboard-summary?platform=kuaishou`） |
| 财务对账 | 按日汇总订单/核销（`/api/meoo-finance-reconcile`，携带快手 token） |
| 评价管理 | 门店/商品评价同步（餐饮评价能力需开放平台单独开通） |

前端本地会话键（与抖音并列）：

- `meoo_kuaishou_merchant_token`
- `meoo_kuaishou_app_id`
- `meoo_kuaishou_merchant_id`

## 六、API 路由说明（技术参考）

| 用途 | 推荐路径 |
|------|----------|
| 绑定 | `POST /api/kuaishou-bind` 或 `/api/meoo-kuaishou-bind` |
| 门店 | `GET /api/meoo-kuaishou-stores` |
| 商品 | `GET/POST /api/meoo-kuaishou-goods-*` |
| 网关统一 | `/api/merchant/kuaishou/*` |

服务端实现：`vite-plugins/kuaishouMerchantGateway.ts`（goodlife 协议，基址 `https://open.kwailocallife.com`）。
