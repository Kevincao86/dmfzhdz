# 灵祺官网

温州灵祺智能科技有限公司官方网站（静态单页）。

视觉：亮色淡紫科技风 · **布局与墨典官网刻意差异化**。

## 本地预览

```bash
cd 灵祺官网
npm run dev
# http://127.0.0.1:5178
```

## 与墨典官网的差异

| | 墨典 | 灵祺 |
|---|---|---|
| 色调 | 深色 ink + mint | 亮色 mist + violet |
| 导航 | 全宽左右顶栏 | 居中悬浮胶囊 |
| Hero | 单栏品牌全幅 | 左右分栏 + 全息球体 |
| 产品 | — / 能力 2×2 | Bento 不对称矩阵 |
| 优势 | 列表 + 信号条 | 粘性双引擎 + 卡片轨 |
| 能力 | 2×2 网格 | 横向能力条 |
| 闭环 | 四列等宽 | 阶梯错位 steps |
| 动效 | 自定义光标拖尾 | 球体星座网格 + 跑马灯 |
