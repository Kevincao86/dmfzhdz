# 灵祺官网

温州灵祺智能科技有限公司官方网站（静态单页）。

视觉：淡紫科技风 · 信息架构参考墨典官网。

## 本地预览

```bash
cd 灵祺官网
npm run dev
# 浏览器打开 http://127.0.0.1:5178
```

## Vercel 部署

**Root Directory 必须选：`灵祺官网`**

| 项 | 值 |
|---|---|
| Framework Preset | Other |
| Install Command | 关闭 Override（或 `echo skip`） |
| Build Command | 关闭 Override（或 `echo skip`） |
| Output Directory | `.` |

## 结构

- `index.html` — 页面结构与文案
- `assets/css/main.css` — 淡紫科技视觉与响应式
- `assets/js/main.js` — 粒子网格、光标、滚动显现、表单提交
- `assets/img/brand/` — 品牌 Logo

## 页面区块

1. Hero — 品牌与 Slogan
2. 产品矩阵 — 商家 ERP / 服务商 ERP / 灵祺星选
3. 核心能力 — 软件开发 · 小程序 · AI 私有化 · 智能体定制
4. 优势与履约闭环
5. 合作流程与咨询表单
