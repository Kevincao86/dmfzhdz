# 剪映 Skill 示例提示词

装好后可直接对 Cursor 说：

## 冒烟

> 用剪映 skill 随便剪一个测试草稿，标题「Cursor剪映冒烟」，素材用 skill 自带 assets（若有），保存后告诉我草稿路径。不要导出。

## 本地素材 Vlog

> 把 `~/Movies/Videos` 里最近的素材剪成 30 秒竖屏 Vlog，轻快 BGM，片头字「周末记录」，草稿名「周末Vlog」。macOS 只生成草稿，我自己在剪映导出。

## 文案 + 配音 + 字幕

> 写一段 20 秒「秋天的第一杯奶茶」口播文案，温柔女声旁白 + 字幕，生成剪映草稿。脚本放 `tools/jianying-jobs/`。

## 与 OpenMontage 区分

> 不要用 OpenMontage。用剪映 skill，把旁白 `xxx.mp3` 对齐字幕并搭时间轴。
