## 0. 执行摘要

本地生活商户不是缺抖音或美团，而是缺一套「会经营、能找达人、交得出、结得清」的操作系统。

灵祺已经把两件事做成同一条流水线，并且跑在生产环境：

1. **商家 ERP：** AI 组品 / Brief / 店铺分析 / 短视频，预览确认后再写入系统。  
2. **星选履约网：** 招募 → 报名 → 探店 / 云剪 → 回链核查 → 结算，商家、PR、达人、拍摄剪辑同一套注册表。

本轮要验证三件事：产品已上线、双边网络已有密度、单位经济可以在杭甬温被审计。500 万用于把已验证的产品能力做成可收费、可复制的模型。

## 9. 建议接触顺序

成功率优先，不追最有名的牌子。完整联络与邮件正文见同目录《机构投递清单与邮件模板》。

| 优先级 | 机构 | 为什么现在更容易成交 |
|---|---|---|
| P0 | 奇绩创坛 | 批次制、认 AI Agent，申请入口标准化 |
| P0 | 天使湾创投 | 杭州早期，在线八问，100 小时反馈，支票快 |
| P0 | 浙商创投 | 植根浙江，投实体数字化 |
| P0 | 温州科创 / 市基金体系 | 星选供给在温州有密度，主体宁波 |

| P1 | 真格基金 | 第一张支票；AI 项目走 prompt 邮箱 |
| P1 | 阿米巴资本 | 投过餐饮 SaaS 语境，懂续费 |

**配比建议：** 浙江国资或浙商创投做「落地与耐心资本」；奇绩 / 天使湾 / 梅花做「速度与品牌」。500 万不必一家吃满，2–3 家拼盘更符合种子轮现实。
