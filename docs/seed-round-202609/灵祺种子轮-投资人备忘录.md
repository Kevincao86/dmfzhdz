## 0. 执行摘要

本地生活商户不是缺抖音或美团，而是缺一套「会经营、能找达人、交得出、结得清」的系统。

灵祺已经把两件事做成同一条线，并且跑在生产环境：

1. **商家 ERP：** AI 组品、出方案、分析店铺、做短视频，商户确认后再写入系统。  
2. **星选履约：** 招募 → 报名 → 探店或云剪 → 回传核实 → 结算。商家、达人、拍摄剪辑在同一套系统里。

本轮要验证三件事：产品已上线、商家和达人都有真实用量、收费和成本能在杭甬温算清楚。400 万用于把已经能用的产品做成能收费、能复制。

### 3.2 与同类产品的差异

| 别人 | 灵祺 |
|---|---|
| 通用聊天助手 | 商户确认后再写入系统，按本地生活规则来 |
| 只发招募的工具 | 和经营 ERP 在同一后台，不只发单 |
| 高客单代运营（再惠等） | 低价自助，服务商可批量带店 |
| 有赞经营 + 种草 | 自己有达人履约，发布后能回传核实 |
| 来客 / 美团后台 | 多平台一起用，不替代平台交易和资金 |

**护城河只承认一条：** ERP 发单 → 星选履约 → 回传 → 续费。拆成两截，就会被「收银系统 + 只发招募的工具」替换。

## 4. 市场与商业模式

### 4.1 市场锚点（公开数据转述）

- 本地商家服务业 2024 年规模超约 13.7 万亿，商家超约 1,300 万。  
- 餐饮线上运营营销支出约 2,420 亿；其中解决方案市场约 691 亿（灼识 × 再惠招股转述）。  
- 前五大合计约 3%，市场极度分散。  
- 杭甬温可服务范围：有达人种草 / 短视频预算的门店，量级约 0.8–1.5 万家。

窗口期约 12–24 个月。全国玩家市占仍低，先把一座城做深的团队还有时间；一旦有赞 / 平台把「经营 + 种草」打包到够用，窗口会关。

### 4.2 收入结构（种子期锚点）

| 来源 | 锚点 | 当前状态 |
|---|---|---|
| 商家订阅 | 约 168 元/月，高阶上浮 | 支付页已出现 168 档，规模化未起 |
| 履约 / 撮合 | 约 10–50 元/单 | 大厅已有预算，结算产品化中 |
| 达人 / PR 会员 | 约 9.9 元/月 | 积分月赠已跑，充值几乎为 0 |

毛利率目标：订阅 75–85%，履约 35–50%。直客获客成本目标 800–3,000 元，服务商带客可摊薄。客户终身价值是获客成本的 3 倍以上，是目标，不是承诺。

## 5. 阶段目标

本轮沟通以下表为准。目标将按上一阶段验证结果滚动调整。

| 节点 | 付费门店 | 同期验证结果 |

并行指标（M12）：月活 / 付费 ≥40%；星选单城活跃达人够完成订单；服务商签约 ≥8；确认收款不再依赖赠送积分。
