## 1. 执行摘要

### 1.1 我们在做什么

灵祺面向**本地生活商户**（餐饮、休闲娱乐、生活服务等），提供：

1. **Merchant AI Agent（商户经营智能体）** — 用自然语言完成组品、达人招募 Brief、评价回复、推广方案等，**先出完整方案、预览确认后再写入 ERP**，降低代运营门槛与误操作风险。  
2. **可验证达人履约网络** — 以统一**运营注册表**连接商家 ERP、运营管理台与**灵祺达人撮合小程序**，覆盖**开环探店**与**云剪闭环**（成片确认 → 发布回链 → AI 核查 → 结算）全链路，让达人合作可追踪、可对账、可复盘。

### 1.2 为什么是现在

- 抖音来客、美团等推动商户「必须会做短视频与达人种草」，但中小商户缺乏工具与方法论。  
- 达人合作仍大量停留在微信群 + 表格，**履约证据薄弱、结算纠纷高发**。  
- 大模型成熟后，**「AI 方案 + 系统执行」** 比纯 SaaS 表单更接近商户真实工作流。

## 2. 市场与痛点

### 2.1 市场规模（叙述逻辑）

- **本地生活线上化**：团购、到店、达人探店已成为商户标配营销支出。  
- **可服务商户池（杭甬温）**：三城常住人口与餐饮商户密度全国前列；仅餐饮商户即达数万级，目标 SAM 为「有达人种草/短视频需求、年营销预算 5–50 万」的商户约 **8,000–15,000 家**。  
- **TAM 扩展**：验证模型后沿长三角复制。

### 2.2 四类核心痛点

| 痛点 | 现状 | 灵祺解法 |
|------|------|----------|
| **不会操盘** | 依赖代运营 PPT，缺乏可持续工具 | AI 智能体 + 门店情报注入 + 九大经营场景 |
| **达人难管** | 通告群、私聊、无统一状态 | 注册表 + 小程序大厅/急单/云剪 + 五阶段流程 |
| **履约不可证** | 截图、口头确认 | 云剪回链 + AI 核查；开环审稿/结款账单 |
| **多客户代运营难** | 表格切换客户 | 服务商版多租户与客户绑定 |

## 3. 解决方案

### 3.1 双引擎架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Merchant AI Agent                         │
│  对话 → 方案/Brief/组品 → 执行预览确认 → ERP 写操作          │
└──────────────────────────┬──────────────────────────────────┘
                           │ 招募单 / 商品 / 活动
                           ▼
┌─────────────────────────────────────────────────────────────┐
│              可验证达人履约网络（注册表驱动）                  │
│  运营台 ── ops_registry_snapshot ── 商家 ERP / 小程序        │
│  开环：报名 → 反选 → 探店 → 审稿 → 结款                      │
│  闭环：成片 → 确认/拒绝 → 下载 → 抖音回链 → AI 核查 → 结算   │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Merchant AI Agent 要点

- **开放对话 + ERP 专有能力**：不拒绝通用问题，经营类需求自动走预览确认。  
- **本地生活规则内嵌**：团购佣金习惯（1%–5%）、组品须可落地正文，禁止空泛步骤。  
- **多场景并行预览**：商品创建与达人招募分卡片确认，避免 AI 一次误执行多业务。  

### 3.3 可验证履约网络要点

- **单一事实来源**：`ops_registry_snapshot` 同步商户、AI 配置、招募单、小程序订单、达人库。  
- **开环探店**：适合「到店体验 + 达人自发创作」；运营反选与排期在 ERP 内阶段化。  
- **云剪闭环**：适合「商家已有成片、达人分发」；**发布链接回传 + AI 核查** 构成可验证锚点。  
- **达人侧粘性**：会员档案、PR 发单、推荐达人、私信（`mp_talent_chat_*`）。

## 7. 区域战略：杭甬温

### 7.1 为何选择浙江金三角

| 城市 | 战略角色 | 商户与达人供给 |
|------|----------|----------------|
| **宁波** | **灰测大本营**（当前 3 家商户所在地） | 餐饮与本地生活密集，线下地推成本低 |
| **温州** | **民营商户与供应链渗透** | 中小商户付费意愿强，适合服务商模式 |
| **杭州** | **品牌与人才窗口** | 总部形象、投融资、产品与设计人才 |

### 7.2 区域打法（18 个月）

1. **宁波**：10 家标杆 + 50 家付费，打造「云剪闭环样板店」案例视频与 PDF。  
2. **温州**：绑定 2–3 家本地代运营（服务商版），每家导入 10+ 商户。  
3. **杭州**：品牌活动、平台生态对接、1–2 场商户沙龙/达人见面会。  
4. **溢出**：台州、绍兴、嘉兴由服务商自然覆盖。

### 7.3 本地化运营清单

- 抖音来客 / 大众点评类目与话术模板（已在 AI 与 Brief 中体现）  
- 同城达人库共建（运营台 + 小程序会员）  
- 商户协会、餐饮连锁总部、区域 MCN 三类 BD 通道

4. **服务商版** 可批量导入门店，单家代运营 **10+ 店/月** 可复制。  
5. **M6** 前完成主链路上线且无重大交付事故（SLA：核心 API 可用性 ≥99.5%），为 **6,000 店** 落地做准备。
