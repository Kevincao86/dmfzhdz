1. 端到端主流程

flowchart TB
  subgraph Phase1["阶段一：剪辑生产"]
    A[PR/运营发布「剪辑任务包」<br/>例：20 条成片位] --> B{全身份可见<br/>仅剪辑身份可认领}
    B --> C1[剪辑师1 认领 15 条]
    B --> C2[剪辑师2 认领 5 条]
    C1 --> D1[批量上传 15 条成片<br/>星选支持拖拽/批量]
    C2 --> D2[批量上传 5 条成片]
    D1 --> E1{条数校验}
    D2 --> E2{条数校验}
    E1 -->|不足| F[提示：还差 N 条，无法提交]
    E2 -->|不足| F
    E1 -->|满 15/15| G1[提交进入 PR 审片队列]
    E2 -->|满 5/5| G2[提交进入 PR 审片队列]
  end

  subgraph Phase2["阶段二：PR 审片"]
    G1 --> H[PR 逐条/批量审片]
    G2 --> H
    H --> I{审片结果}
    I -->|驳回| J[剪辑师修改重传对应条]
    J --> H
    I -->|通过| K[成片进入「已通过池」]
  end

  subgraph Phase3["阶段三：PR 处置"]
    K --> L{PR 操作}
    L -->|已完成| M[剪辑环节结案<br/>不再派发达人]
    L -->|转达人直发任务| N[填写派单表单]
  end

  subgraph Phase4["阶段四：云剪直发（达人）"]
    N --> O[系统生成云剪直发单<br/>人数=已通过条数<br/>每人唯一下载链接]
    O --> P[达人招募大厅 / 云剪任务]
    P --> Q[达人认领 1 条]
    Q --> R[下载专属成片]
    R --> S[规定时间内发布并回传链接]
    S --> T{审核方式}
    T -->|AI 核查| U[回传+AI通过=达人完成]
    T -->|PR 审核| V[PR审核通过=达人完成<br/>逻辑同现有招募单]
    U --> W[订单进度更新 / 待结算]
    V --> W
  end

  M --> X[归档]
  W --> Y[全链路可复盘对账]

2. 剪辑师侧详细流程

flowchart LR
  A[进入剪辑任务包] --> B[查看剩余可认领条数]
  B --> C[输入认领数量 N]
  C --> D{剩余 ≥ N?}
  D -->|否| E[提示可认领上限]
  D -->|是| F[锁定 N 个成片位]
  F --> G[打开批量上传窗口]
  G --> H[拖拽/选择多个文件]
  H --> I{已选文件数 = N?}
  I -->|小于 N| J[提示：还需上传 M 条]
  I -->|等于 N| K[提交]
  K --> L[状态：待 PR 审片]

3. PR 审片 → 转达人直发

flowchart TB
  A[PR 打开剪辑包审片列表] --> B[逐条：通过 / 驳回 / 备注]
  B --> C[已通过池：例如 18/20]
  C --> D{PR 选择}
  D --> E[按钮：已完成]
  D --> F[按钮：转达人直发任务]
  E --> G[剪辑单结案，不生成云剪单]
  F --> H[弹窗派单表单]
  H --> I[认领截止 / 标题 / 平台 / 城市<br/>粉丝要求 / 一口价 / CPS<br/>人数=已通过条数自动<br/>发布截止 / 发布要求<br/>审核方式 AI或PR / 群二维码]
  I --> J[系统为每条已通过成片生成唯一下载链接]
  J --> K[发布至达人招募大厅·云剪任务]
  K --> L[原剪辑单标记：已转直发 N 条]

4. 达人侧（云剪直发）流程

flowchart LR
  A[招募大厅·云剪任务] --> B[查看任务详情]
  B --> C[认领 1 条]
  C --> D[确认接收]
  D --> E[下载系统分配的唯一成片]
  E --> F[按时发布]
  F --> G[回传作品链接]
  G --> H{审核方式}
  H -->|AI| I[AI通过即完成]
  H -->|PR| J[PR审核通过即完成]
  I --> K[该条标记完成]
  J --> K

6. 文字摘要

核心规则：认领按条 · 上传条数=认领条数 · 审片通过才可转直发 · 一人一条视频不重复 · AI/PR 双审核模式。

角色职责
剪辑师按条认领、批量上传成片
PR逐条审片；「已完成」或「转达人直发」
达人云剪直发认领 1 条，发布并回传链接
