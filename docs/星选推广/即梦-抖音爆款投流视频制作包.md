## 一、即梦操作总览（先读再生成）

### 1.1 推荐工作流

```
即梦逐镜生成（5s/镜 × 12 镜）→ 剪映拼接 → AI 配音/真人口播 → 字幕花字 → 导出 1080×1920
```

| 步骤 | 工具 | 说明 |
|------|------|------|
| 分镜视频 | **即梦 · 视频生成 3.0** | 每镜单独生成，选运动幅度「中」 |
| 产品 UI 镜 | **即梦 · 图片生成** + 图生视频 | UI 更稳；或真机录屏 3–5 秒 |
| 拼接配音 | **剪映** | 按下方时间轴对齐口播 |
| 封面 | **即梦 · 图片生成** | 用文末封面 Prompt |

### 1.2 即梦全局参数（每镜统一）

| 参数 | 设置 |
|------|------|
| 比例 | **9:16** |
| 单镜时长 | **5 秒**（60 秒主片 = 12 镜） |
| 风格 | 写实 / 电影感；UI 镜可加「clean mobile app mockup」 |
| 镜头 | 默认；情绪镜用「close-up」「handheld subtle」 |
| 禁止元素 | 微信 logo、二维码、外链网址、竞品 logo、小程序入口 |

### 1.3 即梦 Prompt 写法公式

```
[主体] + [动作] + [场景/光线] + [镜头] + [情绪] + [画质后缀]
画质后缀：cinematic, 4K, shallow depth of field, vertical 9:16, no text watermark
```

**中文 Prompt 即梦也支持**；若效果不稳，用下方「英文 Prompt」列。
