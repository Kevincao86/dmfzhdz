## 五、网页端执行步骤（你照做）

1. 打开 **已登录** 的商家 ERP（生产 `cs.mofangdianai.com` 或本机 `127.0.0.1:5173`）。  
2. 进入 **AI 运营 → 短视频AI处理**。  
3. 确认引擎为 **灵祺视频 / Seedance 1.5 Pro**；时长 **15 秒**；画幅 **9:16**；画质 **1080p**（积分够再用）。  
4. **参考图（推荐 3–5 张，按分镜顺序）：**  
   - `06-dashboard.png`  
   - `02-ai-agent.png`  
   - `14-recruit-hub.png`  
   - `32-shortvideo-ai.png`  
   - `36-leads.png`（可选）  
   路径：仓库内 `docs/星选推广/商家ERP短视频素材/screenshots/`  
5. 把 **第三节「指导文案」** 整段贴进舱体输入 / 脚本区（或先填分镜表再生成）。  
6. 确认口播被识别为带引号对白；系统会走 **有声 + 底部字幕**（勿再另开 TTS 烧录）。  
7. 点 **开始生成短片 / 开始AI处理**，等任务完成 → **预览** → 下载。  
8. 发布抖音：标题可用 `还在五个地方来回切？｜灵祺AI智能ERP`；置顶评论：`评论「试用」私信开通指引`。

**积分：** 短视频按秒扣；15 秒失败重试会再扣，先用 720p 试一条也可。
