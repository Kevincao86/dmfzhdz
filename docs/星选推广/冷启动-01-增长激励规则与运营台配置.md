# 灵祺冷启动 · 增长激励规则 & 运营台配置字段

**版本：** 2026-07-14 · **适用：** 温州及长三角试点 · **活动代号：** `growth_coldstart_v1`  
**关联产品：** 灵祺星选（PR / 达人）· 灵祺AI智能ERP（商家 / 服务商）  
**结算原则：** 探店佣金仍走抖音来客 / 林客；平台激励仅用于 **积分 / 现金返现 / 会员体验**，不替代商单结算。

---

## 一、活动总览

### 1.1 冷启动主力链路（v2）

> **主力量不在达人侧**，而在 **服务商批量导入商户 + PR 持续发单/完单**。达人积分仅作履约留存，不做拉新主航道。

```
服务商签约(S0/S1)
    ↓ 批量导入商户、代发招募
商户 ERP → 星选大厅（供给点火）
    ↓
PR/品牌入驻 → 发单（积分返利）→ 完单（现金返现）← 主激励
    ↓
大厅有单（平台补贴单兜底）→ 达人自然报名接单（积分激励，辅航道）
    ↓
履约闭环 → 样板案例 → 反哺服务商招商
```

| 环节 | 主责角色 | 激励手段 | 目的 |
|------|----------|----------|------|
| **批量供给** | 服务商 | 席位折扣 + 客户导入奖励 | 最高杠杆，一次导入多家商户 |
| **发单习惯** | PR / 品牌方 | 积分赠送 | 点燃供给、养成发单习惯 |
| **完单强化** | PR / 品牌方 | **微信返现（现金）** | 让 PR 有动力跟完撮合闭环 |
| **履约留存** | 达人 / 拍摄 / 剪辑 | **积分赠送** | 维持大厅响应，非拉新主航道 |

### 1.2 激励形式对照

| 活动 | 对象 | 激励形式 | 目的 | 优先级 |
|------|------|----------|------|--------|
| **服务商捆绑激励** | 代运营公司 | 席位折扣 + 客户导入奖励 | 批量导入商户 | ★★★ |
| **PR 完单返现** | PR / 品牌方 / 企业席位 | 微信返现（现金） | 强化供给、验证撮合闭环 | ★★★ |
| **PR 发单返利** | PR / 品牌方 / 企业席位 | 积分赠送 | 养成发单习惯 | ★★ |
| **达人完单积分** | 达人 / 拍摄 / 剪辑 | 积分赠送 | 履约留存、大厅响应 | ★ |

**活动周期建议：** 首期 90 天；预算封顶见文末「财务护栏」。

## 二、PR 发单返利规则表（积分）

### 2.1 返利阶梯（积分）

| 档位 | 触发条件 | 奖励 | 频次限制 | 备注 |
|------|----------|------|----------|------|
| **L0 首开礼包** | 首次成功发布招募至大厅（状态=已发布且大厅可见） | **50 积分** | 每 PR 主体终身 1 次 | 约等于 6 次 Brief 额度（8 积分/篇） |
| **L1 有效发单** | 累计发布 ≥3 单，且其中 ≥1 单有达人报名 | **100 积分** | 每自然月 1 次 | 防「空发刷单」 |
| **L2 活跃发单** | 累计发布 ≥10 单，且其中 ≥3 单进入反选/履约中 | **200 积分** | 每自然月 1 次 | 引导真实撮合 |
| **L3 月度之星** | 当月发布 ≥5 单，且 ≥2 单完单（回链+AI 核查通过） | **300 积分** 或 **专业版 7 天体验** | 每月 Top 20 名 | 可二选一，运营手动审核 |

**积分发放账户：** PR 身份 `套餐桶`（与会员赠送积分同源，不可提现）。

### 2.2 不计入返利的招募

- 草稿 / 已下架 / 运营人工屏蔽
- 同一商单重复发布（标题+门店+预算 48h 内去重）
- 测试账号、内部员工账号（`growth.excludeRegistryIds`）
- 预算为 0 或明显异常（< ¥50 且非云剪/拍摄类）

### 2.3 防薅羊毛

| 规则 | 说明 |
|------|------|
| 主体去重 | 同一营业执照 / 同一 PR 注册表 ID / 同一微信 OpenID 仅享 L0 一次 |
| 月积分上限 | 单 PR 主体每月返利积分 ≤ **500**（L0 除外） |
| 人工复核 | L3 档位、单月返利 >300 积分，运营台待办队列人工确认 |
| 异常熔断 | 同设备 24h 内注册 >3 个 PR → 暂停返利，标 `growth.riskFlag` |

## 三、PR 完单返现规则表（现金）

> 原「达人完单红包」现金池 **整体迁移至 PR 侧**，激励 PR 跟完撮合闭环，而非用现金拉达人注册。

### 3.1 返现阶梯（现金）

| 档位 | 触发条件 | 金额 | 频次 | 发放方式 |
|------|----------|------|------|----------|
| **P0 首撮合返现** | 名下首条招募有达人报名且 **反选通过** | **¥5** | 终身 1 次 | 微信红包 / 企业付款到零钱 |
| **P1 首单完单返现** | 名下首条商单 **回链发布 + AI 核查通过** | **¥30** | 终身 1 次 | 同上 |
| **P2 月完单阶梯** | 自然月名下累计完单 3 单（均核查通过） | **¥30** 额外奖励 | 每月 1 次 | 同上 |
| **P3 优质 PR** | 自然月完单 ≥5 单且投诉率=0 | **¥50** + **「活跃 PR」标签 30 天** | 每月 ≤30 人 | 标签写入 PR 库权重 |

**档位叠加：** P0 + P1 可同享；P2 与 P3 取高不累加（或 P3 含 P2，运营配置 `prCashReward.tierStackMode`）。

### 3.2 完单认定标准（必须全部满足）

1. 商单状态 = 已发布回链（或平台认可的交付凭证）
2. **AI 合规检核** 结论 = 通过（或人工复核通过）
3. 非刷量对（同一 PR 下 7 天内 >5 个完单来自同设备达人 → 人工复核）
4. PR 账号 `status` = 正常，无封禁记录

### 3.3 不发返现情形

- 商单被 PR / 运营取消且无有效交付
- 回链造假、重复提交同一链接
- PR 与达人存在关联账号套利（同 OpenID / 同设备 / 同营业执照）

### 3.4 预算护栏

| 项目 | 建议首期上限 |
|------|----------------|
| PR 返现总池 | **¥15,000 / 月** |
| 单 PR 主体月返现上限 | **¥200** |
| P0+P1 预计人均 | ¥35 × 目标 80 人 ≈ ¥2,800 |

## 四、达人完单积分规则表

> 达人侧 **不发现金**，以积分激励履约留存；拉新靠大厅有单 + 自然流量，不靠现金红包。

### 4.1 积分阶梯

| 档位 | 触发条件 | 奖励 | 频次 | 备注 |
|------|----------|------|------|------|
| **T0 首选积分** | 首次报名商单并被 PR **反选通过** | **20 积分** | 终身 1 次 | 约 2.5 次 Brief 额度 |
| **T1 首单完单积分** | 首次商单 **回链发布 + AI 核查通过** | **80 积分** | 终身 1 次 | 约 10 次 Brief 额度 |
| **T2 阶梯完单** | 自然月累计完单 3 单（均核查通过） | **50 积分** 额外奖励 | 每月 1 次 | 引导持续接单 |
| **T3 优质达人** | 自然月完单 ≥5 单且投诉率=0 | **100 积分** + **「优选达人」标签 30 天** | 每月 ≤50 人 | 标签写入达人库权重 |

**积分发放账户：** 达人身份 `套餐桶`（不可提现）。

### 4.2 完单认定标准

与 PR 完单返现 §3.2 相同。

### 4.3 不发积分情形

- 商单被 PR / 运营取消且达人无有效交付
- 回链造假、重复提交同一链接
- 达人身份为拍摄/剪辑且任务类型为「仅素材」且无发布环节（可配置豁免）

### 4.4 预算护栏

| 项目 | 建议首期上限 |
|------|----------------|
| 达人积分总池（等价） | **≤ ¥3,000 / 月**（按 1 积分 ≈ ¥0.1 估算） |
| 单达人月积分上限 | **≤ 200 积分** |

## 五、服务商捆绑激励（补充）

| 档位 | 条件 | 奖励 |
|------|------|------|
| **S0 签约礼** | 签约服务商版（年付或季付） | 首年 **8 折** + 赠送 **2,000 ERP 积分** |
| **S1 导入礼** | 绑定并激活 ≥10 家客户商家 | **¥500 服务费抵扣** 或等值积分 |
| **S2 发单礼** | 旗下客户通过 ERP 推送星选招募 ≥20 单/月 | 下月服务商席位 **减 1 席费用** 或返 **1,000 积分** |

> 服务商激励走商务合同 + 运营台手工标记，首期可不自动化。**冷启动第一优先级：先签服务商、再批量导入商户。**

### 6.5 运营台页面建议（后续开发）

| 菜单 | 功能 |
|------|------|
| **增长活动 / 总览** | 开关、预算余量、今日发放统计 |

### 6.6 事件触发点（研发对接）

| 事件名 | 触发时机 | 影响活动 |
|--------|----------|----------|
| `recruit.published` | 招募大厅上架成功 | L0、L1、L2 计数 |
| `recruit.signup` | 达人报名 | L1 `minWithSignup` |
| `recruit.selected` | PR 反选通过 | P0、T0 |
| `recruit.fulfillment_passed` | 回链+AI 核查通过 | P1、P2、P3、L3、T1、T2、T3 |

| `payout.redpack` | 红包 API 回调成功 | PR 返现入账 |

## 八、财务与合规护栏

| 项 | 建议 |
|----|------|
| 返现税务 | 小额返现按平台营销费用；月累计 >800 元提醒代扣代缴咨询 |
| 用户协议 | 《活动规则》单独页面，写明反作弊与最终解释权 |
| 审计 | 运营台保留发放日志 180 天：`who / when / amount / recruitId` |
| 关停 | `enabled=false` 后仅停止新发放，已承诺未发放的可人工结清 |

## 九、首期执行方式（无研发时）

1. 运营台导出招募 / 完单 CSV，每周五手工核对  
2. PR 积分：走现有 **运营台手动改档 / 补发积分** 能力  
3. PR 返现：企业微信红包或支付宝批量转账 + 表格台账  
4. 达人积分：运营台手动补发积分  
5. 活动二维码：指向星选小程序 + 渠道参数 `?channel=coldstart_pr` / `coldstart_fws`

**待研发优先级：** `recruit.fulfillment_passed` 自动触发 > PR 返现 API 对接 > PR 积分自动发放 > 达人积分自动发放。
