Lesson 01

本地生活商家为什么越做越累

很多老板有同一种感觉：平台越开越多，人越招越多，生意却没有更轻松。

  • 多平台山：美团、抖音、小红书……商品与活动要重复维护。
  • 内容山：短视频/直播成了标配，产能靠外包或店员加班。
  • 达人山：钱从微信转出去，跟单靠表格和群消息，常踩坑。
累不在「不够勤奋」，而在链路断裂——同一件事被拆成五份工。
Lesson 02

一张图看懂 ERP 能帮你省什么

把经营拆成六个结果词，比背功能列表更有用：

  • 省人力：AI 组品、写 Brief、差评回复。
  • 省外包：短视频出片、云剪混剪、数字人口播。
  • 省试错：招募可追踪到回链，少付冤枉钱。
  • 提速度：说话出方案，确认后再写入。
  • 提闭环：招募 → 履约 → 审片 → 结款看得见卡点。
  • 提清晰度：线索与对账进同一中枢。
一句话：灵祺商家 ERP = 本地生活的 AI 经营中枢。
Lesson 03

注册登录与门店绑定

先把「能登录、能认店」跑通，后面所有 AI 能力才有数据可用。

  • 打开 cs.mofangdianai.com 完成注册/登录。
  • 在设置中绑定抖音来客等平台账号。
  • 核对门店列表与经营类目、毛利率配置。
  • 确认会员权益与 AI 积分额度。

【演示路径】 登录 → 设置 / 系统设置 → 平台绑定 → 商品 / 门店毛利配置

作业：本周完成首次登录，并截图「已绑定平台」状态。
Lesson 04

AI 智能体：九大场景与预览确认

智能体可以闲聊，也可以处理经营任务。涉及写操作时，必须先出「执行预览」，你确认后才真正写入。

  • 创建商品 · 招募达人 · 处理评价 · 优化本地推
  • 跟进线索 · 同步平台 · 分析异常 · 推广文案 · 一键报税

同页还可切换「短视频出片 / 推广文案」。分析异常时，只针对已绑定平台诊断，并覆盖组品、价格、毛利、评价、销量、客群、竞对、Geo 等维度。

【演示路径】 侧栏「AI 智能体」→ 快捷任务 → 核对预览卡片 → 确认执行

铁律：气泡里只看中文方案；不要被机器代码吓到——真正执行看下方确认卡。
Lesson 05

达人招募闭环：从 Brief 到结款

找达人最容易钱打水漂的原因，往往不是「达人不好」，而是流程不在系统里。

  • AI 写三版探店 Brief，选一版下达招募。
  • AI 按预算做档位分配，匹配达人库城市数据。
  • 报名 → 反选 → 探店 → 审片 → 回链 → 结款，状态可追踪。

【演示路径】 智能体「招募达人」或「达人招募」页 → 确认 Brief → 发单到大厅

作业：发一单测试招募（或草稿），截图订单状态。
Lesson 06

短视频出片与数字人口播

周更产能要握在自己手里：可以外包精镜头，但脚本与混剪节奏应在 ERP 内完成。

  • 短视频出片：Agent / 视频生成 / AI 混剪；电脑端还有画布、案例、配乐。
  • 数字人口播：电脑端完整成片；手机端可先 TTS 试听口播稿。
  • 积分与商家 Web / 小程序共用同一租户钱包。

【演示路径】 AI 智能体 → 短视频出片，或侧栏「短视频 AI 处理」

作业：产出 1 条脚本或成片预览（保存到本地）。
Lesson 07

GEO、竞对与本地推线索

曝光不只靠投流：本地搜索可见度、竞对差距、线索跟进，决定「钱有没有花在刀刃上」。

  • GEO：门店信息完整度、问法覆盖、内容新鲜度。
  • 竞对分析：看差距再组品，而不是盲目抄作业。
  • 本地推线索：线索进 ERP，用智能体生成跟进话术。

【演示路径】 GEO 运营 / 竞对分析 / 线索中心

Lesson 08

店铺分析、对账与月度复盘

经营要「看得见」：成交、退款、复购、新老客结构，配合 GPT 图文报告；财务侧可对账与导出报税资料（会员能力）。

  • 店铺分析：图表先看，再按毛利率估算积分跑 AI 报告。
  • 对账：平台账单与核销对齐。
  • 月度复盘：用模板收口本月动作与下月重点。

【演示路径】 店铺 → 店铺分析；财务对账 / 报税管理

作业：填一张本月经营复盘表（成交亮点 + 问题 + 下周动作）。
