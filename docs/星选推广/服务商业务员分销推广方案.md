# 灵祺 ERP 服务商业务员分销推广方案

**方案代号：** `fws_sales_distribution_v1`  
**版本：** 2026-07-14  
**适用产品：** 灵祺AI智能ERP · 商家会员版（¥168/月，及同档位季付 ¥468）  
**关联文档：** [冷启动增长激励规则](./冷启动-01-增长激励规则与运营台配置.md) · [招商话术](./冷启动-03-招商话术-服务商与PR.md) · [会员报价单](./星选平台会员报价单.md) · [分销体系实现设计（个人 vs 服务商）](./分销体系实现设计-个人与服务商.md)  
**核心思路：** 服务商负责招商与客情，业务员负责一线拓客；平台从订阅收入中拿出 **40%** 作为渠道分润，在服务商与业务员之间二次分配。

## 一、分润结构

### 1.1 比例拆解

以 **¥168/月** 为例：

| 角色 | 占订阅收入比例 | 占分润池（40%）比例 | 单月金额 |
|------|----------------|---------------------|----------|
| **平台留存** | 60% | — | ¥100.80 |
| **分润池合计** | 40% | 100% | ¥67.20 |
| └ 服务商 | 16%（40%×40%） | 40% | ¥26.88 |
| └ 业务员 | 24%（40%×60%） | 60% | ¥40.32 |

### 1.2 计算公式

```
分润池 = 实收订阅费 × 40%
服务商佣金 = 分润池 × 40% = 实收 × 16%
业务员佣金 = 分润池 × 60% = 实收 × 24%
```

### 1.3 各档位分润对照表

| 档位 | 实收 | 分润池(40%) | 服务商(16%) | 业务员(24%) |
|------|------|-------------|-------------|-------------|
| 月付 ¥168 | ¥168 | ¥67.20 | ¥26.88 | ¥40.32 |
| 季付 ¥468 | ¥468 | ¥187.20 | ¥74.88 | ¥112.32 |
| 季付月均 | ¥156/月 | ¥62.40/月 | ¥24.96/月 | ¥37.44/月 |

> **季付结算原则：** 季付/年付按「服务期按月摊销」结算佣金。季付 ¥468 分 3 个月，每月各结 ¥62.40 分润池，而非一次性发 ¥187.20。与退款、客诉、税务处理更匹配。

## 二、参与角色与职责

```
灵祺平台 ──签约总代──► 服务商总代 ──管理──► 业务员 ──拓客签约──► 商家客户
    ▲                                                              │
    └──────────────────── 支付订阅 ◄───────────────────────────────┘
              │
              └── 按月结算 ──► 服务商 ──内部分配──► 业务员
```

| 角色 | 定义 | 职责 |
|------|------|------|
| **灵祺平台** | 产品方、收款方、规则制定方 | 归因、核算、向服务商结算、风控 |
| **服务商（总代）** | 已签约 `fws.mofangdianai.com` 的代运营公司 | 招募业务员、培训、客情维护、对内二次分配 |
| **业务员** | 服务商旗下销售/BD，须实名备案 | 陌拜、演示、签约、首月激活跟进 |
| **商家客户** | 购买 ERP 会员版的门店/品牌 | 在线支付或线下对公转账 |

### 2.1 与现有体系衔接

- 服务商在 **fws** 仅做 **分销员配置**，对外推广链接一律指向 **cs**（ERP）与 **dr/星选小程序**（星选会员）。
- 服务商已有 **总代/子代** 结构（`partner_agent`）；**分销员**为轻量账号，与子代公司分离。
- 与冷启动 S0/S1 激励（签约 8 折、导入礼）**可叠加但须设上限**，避免双重补贴击穿毛利（见第六节）。

## 三、归因与资格规则

### 3.1 归因绑定（谁先绑定谁得）

满足以下 **全部条件**，订单计入该业务员：

1. 商家注册/开通时携带 **分销员专属推广码**，落地 **cs**：`https://cs.mofangdianai.com/register?ref=FWS-LQWM-A01`（**不走 fws**）
2. 商家在 **30 天内** 完成首次付费（月付/季付均可）
3. 商家账号状态为 **已激活**（完成门店绑定或首次登录 ERP）
4. 付费渠道为 **灵祺官方收款**（微信/支付宝/对公），非第三方代付

**保护期：** 同一营业执照 / 同一手机号，**90 天内** 仅允许绑定一次业务员，防止抢单。

### 3.2 持续分润 vs 首单奖励

| 模式 | 说明 | 建议 |
|------|------|------|
| **A. 持续分润（推荐）** | 客户每续费一月，分润一月，最长 12 个月 | 激励长期维护，与 SaaS 逻辑一致 |
| **B. 首单一次性** | 仅首月/首季分润，续费不再分 | 成本低，但业务员无续费动力 |

**推荐 A：持续分润 12 个月封顶**

- 客户连续订阅每满 1 个计费周期，结算 1 次对应周期分润
- 累计分润满 **12 个自然月** 后停止（或降至 5% 维护费，可选）
- 客户 **退款/降档/欠费停服**，当期及后续分润暂停

### 3.3 不计入分润的情形

- 试用未转化、内部测试账号
- 服务商 **自用席位**（代运营后台本身）
- 退款成功订单（已结佣金从下期抵扣）
- 刷单、自买自卖（同法人/同设备/同支付账户）
- 低于标准价 **7 折** 的特价单（除非活动白名单）

## 四、结算流程

### 4.1 结算周期（T+15）

```
客户付费（T日）
    ↓
T+7：过退款/争议期，订单「可结算」
    ↓
T+15：生成结算单，服务商确认
    ↓
T+20：平台对公打款至服务商
    ↓
T+25：服务商向业务员发放（内部节奏自定，建议不超过 T+30）
```

### 4.2 结算单据结构

**平台 → 服务商《渠道分润结算单》**

| 字段 | 示例 |
|------|------|
| 结算批次号 | `FWS-202607-001` |
| 服务商名称 / 统一社会信用代码 | XX 代运营有限公司 |
| 结算区间 | 2026-07-01 ~ 2026-07-31 |
| 有效订单数 | 23 笔 |
| 实收订阅合计 | ¥3,864.00 |
| 分润池(40%) | ¥1,545.60 |
| 服务商所得(16%) | ¥618.24 |
| 业务员池(24%) | ¥927.36 |
| 退款抵扣 | -¥67.20 |
| **应付服务商合计** | **¥1,478.40** |

> 平台只与 **签约服务商主体** 结算一笔；业务员部分在结算单中 **明细列示**，由服务商对内支付（平台不直接打款给个人，降低合规风险）。

### 4.3 支付方式

| 对象 | 方式 | 凭证 |
|------|------|------|
| 平台 → 服务商 | **对公银行转账** | 服务商开具 **增值税发票** 后付款 |
| 服务商 → 业务员（员工） | 工资薪金 + 个税代扣 | 工资表、劳动合同 |
| 服务商 → 业务员（兼职/个人） | 劳务报酬 + 代扣个税 | 劳务协议、个税申报 |

### 4.4 退款与 clawback

| 情形 | 处理 |
|------|------|
| 客户 **7 日内全额退款** | 该单分润 **不结算**；已预付则从下期抵扣 |
| 客户 **中途退订** | 未服务月份对应分润 **停止**，已结不退（或按合同协商） |
| 业务员离职 | 在途订单归服务商，**未结算部分** 由服务商按内部制度处理 |

## 五、税务操作

> 以下为实务建议，具体以贵司财务顾问及主管税务机关口径为准。

### 5.1 整体税务链条

```
商家付款 ¥168（含/不含税视开票方式）
    ↓
灵祺确认 SaaS 订阅收入（开具软件服务发票给商家）
    ↓
灵祺支付渠道佣金给服务商（取得服务商发票）
    ↓
服务商支付业务员（工资或劳务，代扣个税）
```

### 5.2 灵祺平台侧

| 事项 | 处理 |
|------|------|
| **商家订阅收入** | 按 **「信息技术服务 / 软件服务」** 开具增值税发票（一般纳税人 6%，小规模 1%/3% 视政策） |
| **渠道分润支出** | 性质：**销售费用 / 渠道推广服务费**，凭服务商发票税前扣除 |
| **发票要求** | 服务商开具 **「现代服务·推广服务费」或「信息技术服务」** 增值税专用发票/普通发票（视灵祺纳税人身份） |
| **代扣代缴** | 平台 **不直接** 向个人业务员付款，避免被认定为劳务报酬扣缴义务混乱 |

### 5.3 服务商侧

服务商为 **企业（公司/个体户）** 时：

| 场景 | 税务处理 |
|------|----------|
| **收到平台分润** | 确认 **其他业务收入或主营业务收入**，就该笔收入向平台开票并缴纳增值税及附加 |
| **业务员是正式员工** | 佣金计入 **工资薪金**，合并个税，正常社保（若构成工资组成） |
| **业务员是兼职个人** | 按 **劳务报酬** 代扣个税，服务商为扣缴义务人 |
| **业务员注册个体户** | 可与个体户签推广合同，个体户自开票，服务商取得成本票 |

**劳务报酬预扣预缴（简易参考）：**

| 单次收入（减 20% 费用后） | 预扣率 |
|---------------------------|--------|
| ≤ 20,000 | 20% |
| 20,000 ~ 50,000 | 30% |
| > 50,000 | 40% |

**业务员月入 ¥40.32 × 20 单 ≈ ¥806**，多数业务员 **单月无需缴税**；但月累计超 **¥800** 或年收入超 **¥120,000** 需关注汇算。

### 5.4 业务员个人侧

| 身份 | 建议 |
|------|------|
| **推荐：服务商员工** | 签劳动合同，佣金走工资，最合规、纠纷最少 |
| **兼职个人** | 签《推广劳务协议》，明确非劳动关系、个税由服务商代扣 |
| **个体户** | 适合月推广量大的资深 BD，自开发票、自负税责 |

**不建议：** 平台直接向大量个人微信发红包结算佣金——易被认定为 **劳务报酬未扣缴**，且难以取得税前扣除凭证。

### 5.5 发票与合同配套清单

| 文件 | 签署方 |
|------|--------|
| 《服务商渠道合作协议》 | 灵祺 ↔ 服务商 |
| 《业务员推广管理办法》 | 服务商内部制度（平台可提供模板） |
| 《推广劳务协议》或劳动合同 | 服务商 ↔ 业务员 |
| 《商家订阅服务协议》 | 灵祺 ↔ 商家（须含退款规则） |
| 月度《渠道分润结算单》 | 灵祺 ↔ 服务商 |
| 增值税发票 | 服务商 → 灵祺 |

## 六、财务护栏

当前冷启动已有 **服务商签约 8 折、导入礼** 等激励。分销分润须设护栏，避免叠加后平台实收过低：

| 护栏项 | 建议值 |
|--------|--------|
| 单客户最低实收 | 不低于标准价 **85%** 才计分润（8 折单需运营白名单） |
| 单服务商月分润上限 | 首期 **¥30,000**（可调） |
| 单业务员月分润上限 | **¥5,000**（防刷单） |
| 分润占订阅收入总比例 | 恒 **40%**，不与 S1 导入礼现金叠加（可改积分） |
| 平台毛利率底线 | 扣除分润 + 云成本后，订阅毛利 ≥ **35%** |

### 6.1 商家实收 ¥168 时的损益简表

```
实收                    ¥168.00
- 渠道分润(40%)         -¥67.20
- 支付手续费(~0.6%)     -¥1.01
- 云资源/API(~¥15)      -¥15.00
≈ 毛利                  ¥84.79（约 50%）
```

40% 分润在 SaaS 行业偏高，但冷启动换量可接受；规模期建议降至 **25%～30%** 或改为「首年 40%、次年 20%」。

## 七、业务员推广话术要点

**一句话：**

> 帮门店开通灵祺 ERP 会员，**¥168/月** 管组品、发达人单、跟履约；您每成功签约并激活一家，**每月可获约 ¥40 推广激励**（由服务商按月发放），客户用得越久您拿得越久，最长 12 个月。

### 7.1 对外表述规范

| 建议说 | 不建议说 |
|--------|----------|
| 推广服务费 / 渠道激励 | 拉人头返利 |
| 客户激活、持续使用才持续结算 | 躺赚、被动收入 |
| ERP → 星选发单闭环 | 只强调返佣金额 |

演示重点：ERP → 星选发单闭环（与 [招商话术](./冷启动-03-招商话术-服务商与PR.md) 一致）。
