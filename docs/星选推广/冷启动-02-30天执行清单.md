# 灵祺冷启动 · 30 天执行清单（按天）

**版本：** 2026-07-14 · **目标区域：** 温州（主）· 宁波/杭州（触达）  
**策略调整：** 主力量在 **服务商 + PR 供给侧**，达人积分仅作履约留存，不用现金拉达人。

**核心 KPI（30 天）：**

| 指标 | 底线 | 挑战 | 优先级 |
|------|------|------|--------|
| 签约服务商 | 2 家 | 5 家 | ★★★ |
| 服务商导入商户触达 | 20 家 | 50 家 | ★★★ |
| PR 注册并发首单 | 30 人 | 80 人 | ★★★ |
| 大厅在招商单 | 周均 ≥10 条 | 周均 ≥25 条 | ★★ |
| 完单（核查通过） | 15 单 | 40 单 | ★★ |
| 样板店案例 | 1 套 | 2 套 | ★★ |
| 达人注册 | 80 人 | 200 人 | ★（自然增长，非主航道） |

**活动文档：** [冷启动-01-增长激励规则与运营台配置.md](./冷启动-01-增长激励规则与运营台配置.md)  
**话术文档：** [冷启动-03-招商话术-服务商与PR.md](./冷启动-03-招商话术-服务商与PR.md)

## 第 1 周：点火（D1–D7）

### D1 周一 · 对内对齐

- [ ] 晨会 30 分钟：过一遍 KPI、**新链路（服务商→PR→大厅）**、分工
- [ ] 发布《活动规则》到 **服务商群 / PR 群** 公告（达人群简略带过）
- [ ] 运营台配置 `coldstart_v1.enabled=true`（或手工台账启用）
- [ ] 小程序分享海报加上渠道码：`channel=coldstart_fws` / `channel=coldstart_pr`

### D2 周二 · 服务商破冰（主航道）

- [ ] 联系名单 Top 10 服务商，约电话/面谈（目标：本周约到 3 场）
- [ ] 发出服务商一页纸方案（fws.mofangdianai.com + S0/S1 激励）
- [ ] 录入 CRM：公司名 / 联系人 / 客户数 / 跟进状态
- [ ] **创始人亲自跟进 Top 3 目标服务商**

### D3 周三 · PR 招募 + 补贴单

- [ ] 在 PR 群发布：**首开发单送 50 积分 + 完单最高 35 元返现**（5+30）活动
- [ ] 私信邀请 15 位认识的 PR / 品牌市场，附操作指引（3 步发单）
- [ ] 运营发布 **2 条平台补贴单**（佣金略高于市场价，标「平台认证」）
- [ ] 检查大厅：补贴单是否展示、报名入口是否正常

### D4 周四 · 服务商试用 + 达人轻触达

- [ ] **优先**：推进已约服务商开通试用账号，导入 1 家测试客户
- [ ] 达人群发布：**完单返积分**（首单最高 100 积分），不做现金红包主推
- [ ] 联系 3 个本地探店博主邀请入驻（自然流量，非主投入）
- [ ] 确认补贴单已有 ≥3 人报名；若无，调高佣金或放宽报名条件

### D5 周五 · 样板店启动

- [ ] 与样板店签约授权（门头拍摄 + 数据脱敏宣传）
- [ ] ERP 完成：门店绑定 → 组品 → AI Brief → 推送星选招募
- [ ] 记录全流程截图（至少 15 张）+ 录屏 3 分钟
- [ ] **由服务商或 PR 身份发单**（示范供给链路）

### D6 周六 · 首场撮合

- [ ] 跟进样板店商单：PR/达人反选、排期
- [ ] 首场线下探店（或拍摄）执行
- [ ] 实时在 **PR 群 + 服务商群** 更新进度（营造「大厅很活跃」氛围）

### D7 周日 · 首周复盘

- [ ] 填写首周数据：服务商意向 __ / PR 注册 __ / 发单 __ / 达人 __ / 报名 __ / 完单 __
- [ ] 发放首周 PR 积分返利 + **首批 PR 完单返现**（手工）
- [ ] 确定第 2 周重点：**服务商签约** or PR 发单不足

**第 1 周里程碑：** ≥1 家服务商意向签约 · ≥10 PR 注册 · ≥1 单进入履约 · 服务商导入 ≥3 家商户触达

## 风险预案

| 风险 | 信号 | 应对 |
|------|------|------|
| **服务商推不动** | 2 周 0 签约 | 改免年费试用 30 天 + 代运营陪跑（**第一应对**） |
| 大厅没单 | 在招 < 5 | 加补贴单、推动服务商代发 |
| 发单了没人报 | 发单 > 报名 ×3 | 提高佣金、PR 群推补贴单、急单标红 |
| 达人不足 | 报名偏少 | **不靠加现金**，靠补贴单佣金 + 自然流量 |
| 羊毛党 | 同设备多号 | 启动风控规则，暂停返利/返现 |
| 完单核查卡壳 | 回链积压 | 人工复核通道 + 简化首月标准 |
