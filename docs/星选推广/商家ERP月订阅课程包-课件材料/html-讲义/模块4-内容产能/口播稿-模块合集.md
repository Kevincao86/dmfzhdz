## 模块开场串词（可选）

家人们好，我们进入「模块4-内容产能」。这一模块会按课表依次录完；每课打开讲义全屏，对照口播稿翻页即可。

### 4.1 商家内容贵在哪：拍摄 / 剪辑 / 口播

内容成本三块：

1. **拍摄**：时间与出镜组织成本。  
2. **剪辑**：外包按时长/条数计费，改稿加钱。  
3. **口播**：脚本质量决定转化，不是嗓音好听就够。

外包适合大片节点；周更适合自己产线 + 必要时精修。模块 4 解决产线，不是影院级调色。

> 完整按页稿见：`4.1-商家内容成本拆解/口播稿.md`

### 4.2 短视频 AI：分镜与分段生成

1. 输入门店与卖点、时长目标（如 30–45 秒）。  
2. 生成分镜：钩子 → 环境/产品 → 价格/权益 → 行动号召。  
3. 改脚本里不真实的承诺。  
4. 导出或进入下一步剪辑/生成。

**钩子公式：**「在[城市]找[品类]，很多人不知道[差异化卖点]……」

> 完整按页稿见：`4.2-短视频AI分镜与分段/口播稿.md`

### 4.3 云剪 / 混剪：素材怎么变成可发成片

1. 上传店内实拍素材（菜品、环境、服务动作）。  
2. 按时间轴对齐分镜。  
3. 一键成片/混剪出草稿。  
4. 检查字幕、敏感词、价格是否与在售一致。  

验收：本周能发，而不是参赛级。

> 完整按页稿见：`4.3-云剪混剪/口播稿.md`

### 4.4 数字人口播：没人出镜也能讲卖点

适用：老板不愿出镜、店员不稳定、多店需统一话术。

流程：稿件确认 → 选择音色 → 生成口播 → 叠加字幕 → 导出预览。  

注意：数字人解决「稳定表达」，信任仍靠真实门店画面与可核验优惠。

> 完整按页稿见：`4.4-数字人口播/口播稿.md`

脚本或成片二选一即可；重点是「可发」而非完美。
