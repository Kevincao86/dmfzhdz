# AI 生图讲义使用说明

## 打开方式

双击打开 [`index.html`](index.html)，点进任意一课。

单课示例：`模块0-开营与认知/0.1-本地生活商家为什么越做越累/index.html`

## 讲解操作

| 操作 | 键 / 操作 |
|------|-----------|
| 下一页 | `→` / `空格` / `PageDown` / 点击右半屏 |
| 上一页 | `←` / `PageUp` / 点击左半屏 |
| 首页 / 末页 | `Home` / `End` |

## 内容说明

- 每课 **≥20 页**，每页是一张 **AI 生成的 16:9 课件图**（非演讲稿提词器）
- 流程：理解讲义 md → 规划 20 页提示词（`prompts.json`）→ AI 生图落入 `slides/` → 写入 HTML

## 重新生成

```bash
# 仅重规划提示词
python3 _gen_ai_image_decks.py --plan-only

# 图片齐套后重写 HTML
python3 _gen_ai_image_decks.py --html-only
```
