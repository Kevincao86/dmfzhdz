# 讲义使用说明

## 打开方式

双击打开总目录，点进任意一课即可投屏讲解。

## 讲解操作

| 操作 | 键 / 操作 |
|------|-----------|
| 下一页 | `→` / `空格` / `PageDown` / 点击右半屏 |
| 上一页 | `←` / `PageUp` / 点击左半屏 |
| 首页 / 末页 | `Home` / `End` |

## 内容说明

- 每课 ≥20 页图片幻灯
- 适合浏览器全屏投屏讲解

## 录播口播稿

- 开课前展示 PPT：[`口播稿总目录-PPT.html`](./口播稿总目录-PPT.html)
- 开场白口播稿：[`开场白口播稿-总目录.md`](./开场白口播稿-总目录.md)
- 总目录：[`口播稿总目录.md`](./口播稿总目录.md)
- 每个模块：`口播稿-模块合集.md`
- 每一课：课目录内 `口播稿.md`（一口气版 + 按页版 + 提词器版）

投屏讲义、另屏打开口播稿即可对着录。
