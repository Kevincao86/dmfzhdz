## 一口气版（可直接念）

**钩子：** 组个双人餐，以前要运营写半天；今天只学会一件事。

### 六步
1. 打开 AI 智能体 →「创建商品」  
2. 输入人话需求（示例）：「周末双人餐，人均 88，含锅底 + 2 荤 2 素，适合家庭，不含酒水，周一至周五晚餐可用。」  
3. 阅读方案：标题、构成、价格、规则、卖点；不对就改字。  
4. 确认执行  
5. 预览卡片逐项核对：价格、包含项、门店、有效期、限购  
6. 配图与入草稿（无图可自动生成，以产品为准）。草稿 ≠ 上架。

### 质量检查清单
- [ ] 价格与毛利心里有数  
- [ ] 包含项可履约  
- [ ] 规则无歧义  
- [ ] 未把内部成本价写进 C 端文案

## 提词器版（去填充 · 连续念）

课号二点三：AI创建商品六步走。本集约二十五分钟，请坐稳。钩子：组个双人餐，以前要运营写半天。今天只学会一件事：对话，确认，预览，入草稿。

草稿不等于上架。环境：测试店。勿用生产环境乱改。敏感信息打码。第一步，打开AI智能体。点创建商品。团购或套餐场景，以你页面文案为准。第二步，输入人话需求。

我示范一句完整约束：周末双人餐，人均八十八，含锅底加两荤两素，适合家庭，不含酒水，周一到周五晚餐可用。请按这句话结构写你的店：人群、价格、包含、禁忌、可用时段，一次说清。发送后等待方案。

等待时不要乱点别的，额度与上下文都在这次对话里。第三步，阅读方案。先看标题是否像消费者会搜的词，不要内部黑话。再看套餐构成：两荤两素是否厨房做得出，有没有把沽清菜写进去。

再看价格与规则：周末是否可用、是否限购、是否预约，有歧义立刻改。不对就改字，不必重写全文。你是编辑，不是重新发明。第四步，确认执行。按提示回复确认或点击确认。这是签字动作。

第五步，预览卡片逐项核对：价格、包含项、门店、有效期、限购。价格：毛利心里有数吗？包含项：门口挂牌能兑现吗？门店：是不是绑对主店？有效期与限购：会不会坑到客诉？五项都过再往下。第六步，配图与入草稿。

无图可走自动生成，以产品能力为准。进入草稿。再次强调：草稿不是上架。上架前再人工终审，尤其是价格和可用时段。质量检查清单：价格毛利有数；包含项可履约；规则无歧义；

未把内部成本价写进C端文案。常见翻车：为了好看把龙虾写进八十八套餐；周末空白却在标题写周末狂欢；酒水含糊导致到店争执。正确姿势：宁可得罪AI，得罪不起顾客。

方案再漂亮，厨房做不出就删。请你暂停，按六步自己做一版。做完截图留着，作业在二点六要交。做不出来的，回看本集，不要跳步。

第1周直播转化钩子也是这句：回看录播课库二点三。和月订阅的关系：你会反复用这六步做旺季换品。模块七旺季专题，本质是六步加速版。收尾复习：打开场景；输入约束；改方案；确认执行；

预览五项；入草稿。六步闭环。片尾提醒：本周同步推进一点四登录作业。没有门店信息，商品草稿也会飘。下一集二点四，AI写招募Brief。我们下集见。
