## 一口气版（可直接念）

首页不是装饰仪表盘，是今日作战图。建议固定顺序：

1. **待办**：今天必须点的事（待确认、待审、待跟）。  
2. **招募进度**：发了几单、报到哪一步、有没有卡住。  
3. **线索入口**：投流/留资是否有新线索未跟。  
4. **其它概览**：按门店重点看组品或内容入口。

老板每天只看首页 3 分钟：有红点就处理，没红点再做增长。不要一进系统就钻设置页。

## 提词器版（去填充 · 连续念）

课号一点二：首页看板怎么读。首页不是装饰仪表盘，是今日作战图。你要建立固定阅读顺序。第一步看待办。待确认、待审、待跟，这些是今天必须点的事。

有红点先处理，没红点再去做增长动作。很多老板一进来就钻设置，或者一进来就找AI玩。顺序错了，今天该审的片没审，该跟的线索没跟。第二步看招募进度。你发了几单，报到哪一步，有没有卡住。

卡在报名还是审片，处理方法完全不同。进度的意义是：别用人情管理合作，用状态管理订单。详情在模块三展开，这里你先知道入口。第三步看线索入口。投流或留资有没有新线索未跟。

投流没有跟进，等于买了电话簿不打电话。第四步看其它概览。按你门店阶段：缺品看组品入口，缺内容看内容入口，缺人看招募入口。我建议的每日习惯：打开ERP，只看首页三分钟。

有红点处理红点；没红点，再去做本周主线动作。三分钟怎么拆？待办一分钟，招募一分钟，线索一分钟。处理不完的进待办，不要东点西点迷路。如果演示账号数据为空，你要能想象：有单时这里会亮。

空不等于没用，是你还没把业务装进来。和一点一的关系：门店信息不准，首页再漂亮也是错的作战图。所以必须先完成门店核对。好，一点二带走一句话：首页是作战图，不是壁纸。
