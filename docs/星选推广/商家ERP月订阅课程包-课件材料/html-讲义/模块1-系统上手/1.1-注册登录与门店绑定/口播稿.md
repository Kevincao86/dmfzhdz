## 一口气版（可直接念）

**【演示】登录页 → 店铺信息 → 平台绑定示意**

1. 进入商家 ERP 登录页，按实际开通方式登录。  
2. 进入店铺信息：核对店名、品类、城市、联系人。这些信息会进入 Brief、招募与内容脚本，错了后面全错。  
3. 门店绑定：确认门店列表与真实门店一致；多店先主店再扩店。  
4. 平台绑定示意：按页面指引关联经营平台（以产品当前入口为准），减少后续重复录入。

**常见卡点**  
- 登录成功但看不到菜单：检查角色与开通状态。  
- 门店名与平台不一致：先统一对外经营名称。

## 提词器版（去填充 · 连续念）

进入模块一，系统上手。课号一点一：注册登录与门店绑定。本集目标：你能独立登录，并完成店铺和门店基础信息核对。演示说明：我用测试店。你们操作生产环境前，改价发单请二次确认。

手机号、真实账单，录屏和交作业都要打码。第一步，打开商家ERP登录页，输入账号登录。登录方式以实际开通为准，可能是手机号或账号密码。登录成功后，不要急着点AI。

先找店铺信息或门店相关入口。信息错了，后面Brief和招募会错一串。逐项核对：店名、品类、城市、联系人。店名建议与对外经营名称一致，

避免一边叫老字号一边叫分店简称。品类会影响到后续AI组品的默认语境，城市会影响达人匹配与本地搜相关能力，所以不要留空，也不要随便填。联系人填能接通的人，后面履约接待会用到。

接着看门店绑定。确认门店列表和真实门店一致。多店老板先绑定主店，先把一条流水线跑通，再扩店。平台绑定示意：按页面指引关联你需要经营的平台账号。绑定是为了减少组品、对账、线索的重复录入，

以产品当前入口为准。常见卡点一：登录成功但看不到菜单。检查账号角色和开通状态，是否权益未生效，或进错了环境。常见卡点二：门店名和平台侧不一致。先统一对外名称，再同步平台侧，不要三套名字并存。

常见卡点三：联系人电话乱填或留空，导致达人到店找不到人。核对清单：能登录；店铺信息完整；主门店正确；知道平台绑定入口在哪。四条都过，一点一才算完成。

你现在可以暂停视频，自己做一遍。做完不要关掉，下一集一点二教你首页怎么读，那是每天三分钟的作战图。再次强调：本课程所有演示优先测试店。

你正式发招募、正式上架前，自己再人工终审一遍。好，一点一结束。请记住：先门店，后AI。
