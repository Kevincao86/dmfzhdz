## 模块开场串词（可选）

家人们好，我们进入「模块1-系统上手」。这一模块会按课表依次录完；每课打开讲义全屏，对照口播稿翻页即可。

### 1.1 注册登录与门店绑定

**【演示】登录页 → 店铺信息 → 平台绑定示意**

1. 进入商家 ERP 登录页，按实际开通方式登录。  
2. 进入店铺信息：核对店名、品类、城市、联系人。这些信息会进入 Brief、招募与内容脚本，错了后面全错。  
3. 门店绑定：确认门店列表与真实门店一致；多店先主店再扩店。  
4. 平台绑定示意：按页面指引关联经营平台（以产品当前入口为准），减少后续重复录入。

**常见卡点**  
- 登录成功但看不到菜单：检查角色与开通状态。  
- 门店名与平台不一致：先统一对外经营名称。

> 完整按页稿见：`1.1-注册登录与门店绑定/口播稿.md`

### 1.2 首页看板怎么读

首页不是装饰仪表盘，是今日作战图。建议固定顺序：

1. **待办**：今天必须点的事（待确认、待审、待跟）。  
2. **招募进度**：发了几单、报到哪一步、有没有卡住。  
3. **线索入口**：投流/留资是否有新线索未跟。  
4. **其它概览**：按门店重点看组品或内容入口。

老板每天只看首页 3 分钟：有红点就处理，没红点再做增长。不要一进系统就钻设置页。

> 完整按页稿见：`1.2-首页看板怎么读/口播稿.md`

### 1.3 会员权益与 AI 额度说明

AI 能力是「有额度的生产力」，不是水龙头。

学习期三个预期：

1. **免费与会员能力不同**：部分导出、高级分析、更高额度可能在会员侧。  
2. **额度会消耗**：组品、Brief、话术、报告都会占用；先想清楚再点生成。  
3. **预览确认不浪费信任**：额度用在出方案，写入仍需你确认（见模块 2）。

课程月订阅若含试用/会员，以实际套餐为准；口播不要承诺「无限次」。

> 完整按页稿见：`1.3-会员权益与AI额度说明/口播稿.md`
