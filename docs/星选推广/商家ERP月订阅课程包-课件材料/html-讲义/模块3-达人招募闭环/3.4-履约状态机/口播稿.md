## 提词器版（去填充 · 连续念）

课号三点四：报名，到反选，到探店，到审片，到回链。本集约二十五分钟，把合作当成订单状态，不要当成人情。我按状态机给你拆。状态一：报名。你要看匹配度、历史风格，不要只看粉丝数。

粉丝多但从不拍你的品类，匹配失败概率高。状态二：反选。明确人选与档期，必须在系统确认，口头答应不算数。口头答应是跟单乱的温床。状态三：探店或拍摄。你要提供接待与卖点清单：谁接待、拍什么、不能拍什么、

主推套餐是什么。现场没人接待，是高频翻车。状态四：审片。核对卖点有没有讲到、字幕有没有错敏、价格是否与在售一致。只看是否好看不够，好看但卖点错了，等于白拍。状态五：回链。核对链接或数据凭证是否入库。

私发链接未入库，结款时一定扯皮。卡在哪一步，就只解决哪一步。不要在审片阶段回头改预算；不要在回链阶段才发现反选错人。

状态机的价值是：让团队同语言。老板问进度，你不说「差不多了」，你说「卡在审片，差一条字幕」。演示：若有示例订单，按状态点进查看；没有就用表格投屏，把五个状态念熟。

暂停：用你三点六将要发的测试单，预演每个状态你要做什么。下一集三点五，结款与核对：怎么证明达人真的发了。
