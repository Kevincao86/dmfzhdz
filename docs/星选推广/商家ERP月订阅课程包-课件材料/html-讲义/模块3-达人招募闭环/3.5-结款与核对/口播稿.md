## 提词器版（去填充 · 连续念）

课号三点五：结款与核对，怎么证明达人真的发了。纪律先立：无回链，不轻易结尾款。结款依据应来自系统可核对信息：回链、发布凭证、AI核查结果，以产品展示为准。

课程不讲内部运维细节；学员侧会三件事就够。第一，在订单里找到回链或凭证入口。找不到入口，先别打款，先找页面或问助教路径，不要回到纯微信结款。第二，

核对是否符合Brief：卖点、时长、平台、是否露店。不符合就标记异常再沟通。第三，异常先标记再沟通，不要先打款再追片。先打款，你就从甲方变成催债人。

和三点一呼应：无回链正是亏钱三件套最后一环。和价值图呼应：这是省试错的最后一公里。演示时真实结算账号、金额必须打码。好，三点五结束。下一集三点六交招募单截图。
