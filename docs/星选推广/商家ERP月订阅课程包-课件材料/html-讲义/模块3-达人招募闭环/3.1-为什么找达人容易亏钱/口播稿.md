## 一口气版（可直接念）

达人合作亏钱，很少亏在「坑位费贵」，更多亏在「不确定」。

1. **群发**：同一套话术轰炸，匹配度低。  
2. **跟单乱**：进度在微信里，人一忙全断。  
3. **无回链**：片发了但对不上，结款靠感觉。

ERP 要你改变的习惯：一切以订单状态为准，不以群消息为准。

## 提词器版（去填充 · 连续念）

课号三点一：为什么找达人最容易钱打水漂。本集先纠偏：达人合作亏钱，很少只亏在坑位费贵，更多亏在不确定。不确定有三件套：群发、跟单乱、无回链。第一件：群发。同一套话术轰炸几十上百个达人，

看起来热闹，匹配度却很低。对方回了也不知道适不适合你的品类和门店调性。你把筛选工作甩给命运，命运就用浪费预算回报你。第二件：跟单乱。进度在微信里，人一忙全断。

谁答应周几到店，谁说片子后天交，全靠翻聊天记录。换一个对接人，信息就断层。月底你甚至说不清哪些合作还活着。第三件：无回链。片发了但对不上，结款靠感觉。

有人说发了，链接找不到；有人链接有了，内容却和Brief不符。你先打款再追片，主动权就没了。ERP要你改变的习惯是：一切以订单状态为准，

不以群消息为准。群可以沟通温度，但状态必须进系统。下一集三点二，我们从Brief走到发招募单，让订单在大厅可见，或至少进入可追踪状态。学习期可以用测试招募或草稿，先练手形。

请你对照自己：过去三个月有没有付过一笔说不清回链的钱？有的话，三点一就已经值回。好，本集结束，我们进入发单全流程。
