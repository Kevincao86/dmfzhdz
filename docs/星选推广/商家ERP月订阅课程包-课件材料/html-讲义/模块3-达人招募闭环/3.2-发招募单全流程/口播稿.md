## 提词器版（去填充 · 连续念）

课号三点二：发招募单，从Brief到大厅可见。这是第二周直播主课锚点。目标：走通招募页全流程，使订单可追踪。演示用测试店，学习期优先测试招募或先存草稿。

从Brief进入发单，或新建招募。填写标题：让达人三秒看懂品类、城市、合作类型。填写门店：绑对主店。填写预算：写清总预算，尽量注明是否含交通或餐补，避免后期扯皮。

填写人数或档位：你要几个人，什么量级，先有框架，细节三点三再拆。填写截止时间：给报名留窗口，也给自己留反选时间。填写探店要求：到店时段、是否真人出镜、拍摄动线。

填写交付物：几条视频、几张图、是否要口播关键词。填写禁区：竞品、绝对化医疗功效、夸张承诺。预览招募信息，确认无错别字与冲突规则。例如标题写周末，规则却工作日才接待，这就是冲突。发布。

学习期可先存草稿，或标题加「测试」字样。发布后回到看板，确认该单出现在进度里。找不到进度，等于你还在用感觉管理。发单前三十秒自检：预算是否含税含交通？

是否写清到店时段？是否要求真人出镜？三条过再点发布。暂停：自己走一遍，截图留着，三点六要交。做不出来回看本集，不要跳到结款。好，三点二核心流程结束。
