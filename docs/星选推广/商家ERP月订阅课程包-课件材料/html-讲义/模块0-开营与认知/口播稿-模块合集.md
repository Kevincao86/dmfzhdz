### 0.1 本地生活商家为什么越做越累

很多本地生活老板有同一种感觉：平台越开越多，人越招越多，生意却没有更轻松。

### 第一座山：多平台
美团、抖音、小红书、高德……后台各不相同，商品要重复维护，活动规则各写各的。你不是不会经营，是同一件事被拆成五份工。

### 第二座山：内容
短视频和直播成了标配，但拍摄、剪辑、口播往往靠外包或店员加班。产能不稳定：旺季求人改片，淡季又不知道发什么。

### 第三座山：达人
探店、种草、星选合作，钱从微信转出去，跟单靠表格和群消息。常见结局：人来了片没回、回了链不对、对了款扯皮。

### 叠加结果
雇人增加管理半径，外包增加沟通成本，老板自己变成「最高级群管理员」。

**不是教你「怎么开抖音」，是教你「怎么用 AI 把开团、招达人、做内容、对账做成一条流水线」——少雇人、少外包、少踩坑。**

### 0.3 月订阅怎么学：直播节奏 + 作业 + 工具开通

月订阅 = 学 + 练 + 用。

**学**：每周 1–2 场直播（含回放）+ 录播库模块 0–6 + 模块 7 月更专题。  
**练**：每周一小作业（组品 / Brief / 成片 / 对账）。  
**用**：配套 ERP 试用/会员。

开通五步：打开 `cs.mofangdianai.com` → 注册登录 → 店铺/门店 → 看权益与 AI 额度 → 测试心态首次 AI 组品。

正式学员务必完成 0.3 + 1.4。
