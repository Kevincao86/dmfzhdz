**学**：每周 1–2 场直播（含回放）+ 录播库模块 0–6 + 模块 7 月更专题。

## 提词器版（去填充 · 连续念）

课号零点三：月订阅怎么学。主题是直播节奏、作业，和工具开通。先纠正误解：月订阅不是买一堆视频扔给你，而是三件事同时发生：学、练、用。第一，学。

每周一场到两场直播，含回放，负责现场跟着做。录播课库把模块零到六铺齐，负责补基础和反复回看。模块七是月更专题，按月换题，比如旺季组品、达人怎么选，这是续费钩子，也是场景换季的更新权。第二，练。

每周一个小作业。典型是商品草稿截图、Brief或招募单截图、脚本或成片预览、线索话术截图、月末复盘表。作业不求完美，求闭环跑通。做不出来，回看对应课号，别硬扛，也别只在群里问不做。

第三，用。配套ERP试用或会员，和实际售卖SKU对齐。工具不开，课就只是纪录片。下面开通五步，请跟着做或先截图保存。第一步，打开地址栏输入cs.mofang

dianai.com，进入商家ERP。第二步，注册或登录，按你收到的开通方式来。第三步，完善店铺信息与门店绑定，店名品类城市联系人要跟真实门店一致。

第四步，确认会员权益与AI额度，详见课一点三。第五步，用测试心态完成首次AI组品，详见课二点三。草稿不等于上架，先跑通再谈正式上架。四周直播节奏：第一周开营加AI组品；第二周现场发招募；

第三周口播或混剪；第四周线索跟进加月度复盘。每场大约九十分钟：开场价值一图，复盘作业，主课演示，答疑，最后下单引导。录播补你没跟上的细节。免费试听建议先看零点一、零点二；

正式学员务必完成零点三和一点四，避免买了课不会登录。本周作业预告：完成首次登录与门店核对，正式验收在一点四，提交店铺信息页截图，手机号打码。月订阅五条权益再说一遍：当月直播含回放；

录播全库按月追加；每周作业；答疑；配套工具权益。功能会月更，场景会换季。你买的不是一次课，是持续能跟着干的经营更新。好，零点三结束，下一集进入模块一登录。
