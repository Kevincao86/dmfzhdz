直播场次编排

四周，把「会」变成「做过」

  • 第 1 周
    开营 + AI 组品现场做
    对齐认知，当场出组品
  • 第 2 周
    现场发一单招募
    Brief → 发单 → 大厅可见
  • 第 3 周
    现场出一条口播 / 混剪
    内容产能闭环
  • 第 4 周
    线索跟进 + 月度复盘
    获客与经营收尾
订阅方法论

月订阅 = 学 + 练 + 用

学
直播 + 录播库
每周 1–2 场直播（含回放）+ 模块 0–7
练
每周一小作业
组品 / Brief / 成片 / 对账，选一完成
用
ERP 真机练习
打开 cs.mofangdianai.com，用额度测一遍
散点经营一定累；流水线才省人、省口径、省月底扯皮。
