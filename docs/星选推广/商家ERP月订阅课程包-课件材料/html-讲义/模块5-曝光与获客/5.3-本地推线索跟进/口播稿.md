## 一口气版（可直接念）

1. 完成投流/线索相关绑定（按页面指引）。  
2. 线索列表出现新客。  
3. AI 生成跟进话术：问诊需求 → 给套餐建议 → 邀约到店/私信。  
4. 跟进结果回填，避免重复骚扰。

投流没有线索跟进，等于买了电话簿不打电话。
