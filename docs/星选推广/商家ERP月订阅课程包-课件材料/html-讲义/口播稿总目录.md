# 演讲口播稿总目录

面向 **html-讲义** 投屏录播：每个子项目（模块）有合集，每课有独立 `口播稿.md`。

## 开课前（总目录展示）

| 用途 | 文件 |
|------|------|
| 展示 PPT（14 页，← → 翻页） | [口播稿总目录-PPT.html](./口播稿总目录-PPT.html) |
| 每页幻灯图片（JPG） | [口播稿总目录/slides/](./口播稿总目录/slides/) · [清单](./口播稿总目录/slides清单.md) |
| 开场白口播稿 | [开场白口播稿-总目录.md](./开场白口播稿-总目录.md) |

开营直播 / 录播片头：先投屏 PPT，对着开场白念 4–6 分钟，再进 `0.1`。

## 怎么用

1. 打开 `html-讲义/index.html` 进入对应课。
2. 同目录打开 `口播稿.md`，按「按页口播」翻页念。
3. 赶进度可用「一口气版」。
