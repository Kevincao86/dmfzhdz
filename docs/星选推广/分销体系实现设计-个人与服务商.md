## 一、核心原则（v2 修正）

| 原则 | 说明 |
|------|------|
| **fws 只做配置，不做落地** | 服务商在 `fws.mofangdianai.com` **设置分销员**、查看数据；**不在 fws 注册客户、不在 fws 收分销链接** |
| **分销落地走 cs + dr** | 商家订阅 → **cs**；星选 PR/达人会员 → **dr** + **星选小程序** |
| **双通道分销员** | **个人分销员**（平台审核）与 **服务商分销员**（fws 内配置）共用同一套码表与归因，分润规则分轨 |
| **星选支持个人分销** | 个人分销员可推广 dr/小程序星选会员，与 ERP 推广并列 |
| **一个码，多产品落地** | 同一 `ref` 在用户进入 cs 或 dr/小程序时分别绑定对应产品线归因 |

```
                    ┌──────────────────────────────────────┐
                    │     fws.mofangdianai.com              │
                    │  【仅配置】分销员管理 · 数据看板       │
                    │  服务商总代登录 → 设置业务员/分销员    │
                    └─────────────────┬────────────────────┘
                                      │ 生成 ref 码
          ┌───────────────────────────┼───────────────────────────┐
          │                           │                           │
          ▼                           ▼                           ▼
   cs.mofangdianai.com        dr.mofangdianai.com          星选小程序
   【商家 ERP 落地】            【星选 Web 落地】             【星选 MP 落地】
   注册/订阅 ¥168+             PR/达人注册/会员              同 dr 账号体系
          │                           │                           │
          └───────────────────────────┴───────────────────────────┘
                                      │
                                      ▼
                         统一 attribution + commission
                                      │
                                      ▼
                    admin.mofangdianai.com 运营管控台
                    审核 · 归因 · 流水 · 结算
```

## 二、产品域与分销落地矩阵

| 域名/端 | 产品 | 分销落地内容 | 付费触发分润 |
|---------|------|--------------|--------------|
| **cs** | 灵祺AI智能ERP 商家版 | 商家注册、会员订阅（¥168/月等） | `merchant_payment_orders` 订阅类 |
| **dr** | 灵祺星选 Web | PR/达人/拍摄/剪辑注册、星选会员订阅 | 星选会员 checkout / 支付确认 |
| **星选小程序** | 灵祺星选 MP | 同 dr 身份注册与会员 | 同上，与 dr 共用 registry |
| **fws** | 服务商版 ERP | ❌ **不分销落地**；仅分销员配置与报表 | — |
| **admin** | 运营管控台 | 个人分销员审核、全局策略、结算 | — |

### 2.1 推广链接规范（全部指向 cs / dr / 小程序）

| 推广目标 | 链接模板 | 示例 |
|----------|----------|------|
| ERP 商家 | `https://cs.mofangdianai.com/register?ref={code}` | `?ref=FWS-LQWM-A01` |
| ERP 商家（小程序壳） | 灵祺 ERP 小程序 path + scene | `scene=ref%3DFWS-LQWM-A01` |
| 星选 PR | `https://dr.mofangdianai.com/register?ref={code}&role=pr` | 个人/服务商码通用 |
| 星选达人 | `https://dr.mofangdianai.com/register?ref={code}&role=talent` | 同上 |
| 星选小程序 | `/pages/welcome/welcome?ref={code}` | onLaunch 持久化 |

> **禁止：** `fws.mofangdianai.com/register?ref=...` 作为对外推广链接。

### 2.2 fws 内「分销设置」仅产出素材

服务商在 fws **设置 → 分销设置** 中：

1. 新建/编辑分销员（姓名、手机、工号）
2. 系统生成码（关联 `partner_tenant_id` + `salesperson_id`）
3. **一键复制** cs 链接、dr 链接、小程序码（三种落地，同一 ref）
4. 查看各分销员在 cs / dr 两线的绑定数与预估分润（只读）

## 三、分销员类型

### 3.1 对比

| 维度 | 个人分销员 | 服务商分销员 |
|------|------------|--------------|
| **身份** | 独立自然人/个体户 | 服务商组织内业务员 |
| **开通方式** | dr/cs 申请页 或 运营台审核 | **fws → 分销设置** 由总代创建 |
| **是否需要 fws 账号** | 否 | 否（分销员本人不上 fws） |
| **推广码前缀** | `IND-` | `FWS-{slug}-` |
| **分润接收** | 平台 → 个人 | 平台 → 服务商对公 → 内部分配 |
| **可推广产品** | cs ERP + dr/小程序 星选 | cs ERP + dr/小程序 星选 |
| **ERP 分润池** | 30%（建议） | 40%（服务商 16% + 分销员 24%） |
| **星选分润池** | 25%（建议，见 §5.2） | 35%（服务商 14% + 分销员 21%） |

### 3.2 与 `partner_agent`（子代公司）的关系

| 实体 | fws 菜单 | 是否分销落地 | 说明 |
|------|----------|--------------|------|
| **服务商分销员** | 分销设置 | 否，链到 cs/dr | 轻量账号，本方案核心 |
| **子代公司** | 子代管理（已有） | 否 | 独立 `partner_agent` 租户，代运营用 |

子代公司与分销员 **菜单分离**，避免销售混淆。

## 四、归因模型（按产品线拆分）

同一 `ref` 码，用户从不同入口进入，绑定 **不同产品线** 的 attribution，互不覆盖。

### 4.1 归因表（扩展）

```sql
distribution_attributions (
  id                      uuid PK,
  ref_code                text NOT NULL,
  channel_type            text,        -- individual | partner
  affiliate_id            uuid NULL,
  partner_tenant_id       uuid NULL,
  salesperson_id          uuid NULL,

  -- 被推广主体（按产品线一条）
  subject_type            text NOT NULL,
    -- erp_merchant | xingxuan_pr | xingxuan_talent | xingxuan_shoot | xingxuan_edit
  subject_registry_id     text NOT NULL,   -- tenantId 或 mpPrUserId / mpTalentMemberId
  landing_surface         text NOT NULL,   -- cs | dr | mp

  bound_at                timestamptz,
  activated_at            timestamptz NULL,
  first_paid_at           timestamptz NULL,
  status                  text,
  dedupe_key              text,
  unique (subject_type, subject_registry_id)
)
```

**示例：** 分销员 `FWS-LQWM-A01` 既推了商家 A（cs），又推了 PR 张三（dr）→ **两条 attribution**，同一 ref、同一 salesperson。

### 4.2 ref 持久化（各端）

| 端 | 时机 | 存储 |
|----|------|------|
| **cs** 注册页 | URL `?ref=` | `localStorage.pendingRef` + 提交注册 API |
| **dr** 注册页 | URL `?ref=` | 同上 |
| **星选小程序** | `onLaunch` / `onShow` query | `wx.setStorageSync('pendingRef')` |
| **跨端** | 30 天 TTL | 过期清空，自然注册 |

### 4.3 绑定 API 挂载点

| 产品线 | 注册 API | 文件 |
|--------|----------|------|
| ERP 商家 | `POST /api/meoo-auth-register` | `authRegisterProvision.ts` |
| 星选 PR | `POST /api/meoo-ops-mp-pr-user-register` | `meoo-ops-mp-pr-user-register.ts` |
| 星选达人 | `POST /api/meoo-ops-mp-talent-member-register` | `meoo-ops-mp-talent-member-register.ts` |
| dr Web 注册 | 同上（dr 调 mp registry API） | `灵祺达人履约管理后台` 注册流 |

请求体统一增加可选字段：`refCode?: string`

## 五、分润规则（双产品线）

### 5.1 ERP 商家线（cs）

沿用 [服务商业务员分销推广方案](./服务商业务员分销推广方案.md)：

| 角色 | 占实收 |
|------|--------|
| 平台 | 60% |
| 服务商 | 16% |
| 服务商分销员 | 24% |
| **个人分销员** | **30%**（整池，无二次拆分） |

触发：`merchant_payment_orders` 订阅 verified → `distribution_commission_ledger`（`product_line=erp`）

### 5.2 星选会员线（dr + 小程序）

| 角色 | 占星选会员实收 | 示例（PR 专业 ¥129/月） |
|------|----------------|-------------------------|
| 平台 | 65% | ¥83.85 |
| **个人分销员** | 25% | ¥32.25 |
| 服务商 | 14% | ¥18.06 |
| 服务商分销员 | 21% | ¥27.09 |

触发：星选会员支付确认（运营台 checkout 或在线支付）→ ledger（`product_line=xingxuan`）

> 星选探店 **CPS 佣金仍走来客/林客**，与本分销体系无关。

### 5.3 个人分销员在星选的优势话术

> 一条 IND 码，推 ERP 商家赚订阅分润，推 PR/达人开星选会员同样计佣。

## 六、fws「分销设置」模块（仅配置）

### 6.1 位置与权限

- **路径：** fws → 设置 → **分销设置**（新增 Tab，与「子代管理」并列）
- **可见：** `edition=partner` 且运营台开通 `distribution.partnerEnabled`
- **不可见：** 对外注册链接、客户代录入时分润码（代录入走 cs 侧商家 tenant）

### 6.2 功能清单

| 功能 | 说明 |
|------|------|
| 分销员列表 | 姓名、手机、工号、状态、绑定客户数（cs/dr 分列） |
| 新建分销员 | 手机+工号，自动生成 `FWS-{slug}-{工号}` |
| 推广素材 | 复制 cs / dr / 小程序三种链接；下载小程序码 |
| 数据看板 | 本月新增绑定、付费数、预估分润（ERP / 星选分 Tab） |
| 结算明细 | **只读** 平台→服务商批次（分销员明细列示，内部分配线下） |

### 6.3 明确不做

- ❌ fws 注册页带 ref
- ❌ 在 fws 替客户开通商家 tenant 时自动吃分润（除非该客户之后从 cs 完成订阅且已有 attribution）
- ❌ 分销员登录 fws（分销员用 dr「推广伙伴」轻量页或仅收结算短信）

### 6.4 研发文件

| 文件 | 说明 |
|------|------|
| `PartnerDistributionSettingsSection.tsx` | fws 分销设置 UI（新建） |
| `SettingsPage.tsx` | 增加 tab `partner_distribution` |
| `meoo-partner-salespersons.ts` | 分销员 CRUD API |
| `meoo-partner-distribution-stats.ts` | 看板聚合 |

## 七、个人分销（cs + dr + 星选）

### 7.1 申请入口（不走 fws）

| 入口 | URL / 路径 |
|------|------------|
| cs 推广伙伴页 | `https://cs.mofangdianai.com/partner-program` |
| dr 推广伙伴页 | `https://dr.mofangdianai.com/partner-program` |
| 星选小程序 | 「我的 → 成为推广伙伴」 |
| 运营台代录 | admin → 渠道分销 → 个人分销员 |

**实名认证（KYC）为申请前置条件，接口详见 → [分销员实名认证接口设计](./分销员实名认证接口设计.md)**

- **微信小程序：仅微信实名**（城市服务校验或人脸核身 + 服务端 query）
- **cs/dr Web：微信内用微信、支付宝内用支付宝**
- 抖音可选，首期建议微信 + 支付宝

### 7.2 审核通过后

- 生成 `IND-xxxxxx`
- 开通 **dr 轻量推广页**（或 cs 同页）：展示双产品链接、绑定列表、待结算
- **不开 fws 账号**

### 7.3 个人分销员能力

| 能 | 不能 |
|----|------|
| 推广 cs ERP + dr/小程序星选 | 登录 fws |
| 查看 IND 码与两线业绩 | 代运营商家 |
| 修改收款账户（运营审核） | 创建下级 |

## 九、端到端流程

### 9.1 服务商分销员推 ERP 商家

```
1. 总代 fws → 分销设置 → 新建分销员「张三 A01」
2. 复制 cs 链接：https://cs.mofangdianai.com/register?ref=FWS-LQWM-A01
3. 商家打开 cs 注册 → ref 写入 storage → 注册成功 → attribution(erp_merchant)
4. 商家 cs 内付 ¥168/月 → ledger 计提 → T+7 可结算 → 平台对公打服务商
5. 服务商内部分配张三 24% 部分
```

### 9.2 个人分销员推星选 PR

```
1. 李四 dr 申请个人分销 → 运营审核 → IND-K7M2P9
2. 分享 dr：https://dr.mofangdianai.com/register?ref=IND-K7M2P9&role=pr
3. PR 注册 → attribution(xingxuan_pr, landing=dr)
4. PR 开通专业版 ¥129/月 → ledger(xingxuan) 个人 25%
5. 平台月结劳务/对私
```

### 9.3 同一分销员两线并行

服务商分销员 A01 可同一天：

- 推 cs 商家 → attribution `erp_merchant`
- 推 dr PR → attribution `xingxuan_pr`

同一 ref，两条流水，看板分列展示。

## 十、数据库与 API（摘要）

### 10.1 表结构

与 v1 相同，增加字段：

- `distribution_attributions.subject_type` / `landing_surface`
- `distribution_commission_ledger.product_line` (`erp` | `xingxuan`)
- `distribution_codes` 不变（码不区分产品，落地端区分）

### 10.2 新增/扩展 API

| API | 端 |
|-----|-----|
| `GET /api/meoo-distribution-ref-resolve?ref=` | cs / dr / mp 共用 |
| `POST /api/meoo-distribution-affiliate-apply` | cs / dr |
| `POST /api/meoo-auth-register` + `refCode` | cs |
| `POST /api/meoo-ops-mp-pr-user-register` + `refCode` | dr / mp |
| `POST /api/meoo-ops-mp-talent-member-register` + `refCode` | dr / mp |
| `GET/POST /api/meoo-partner-salespersons` | **仅 fws 调用**（配置） |
| `GET /api/meoo-partner-distribution-stats` | **仅 fws 调用**（只读） |
| `GET/POST /api/meoo-ops-distribution-*` | admin |

### 10.3 星选会员支付钩子

在星选会员 checkout 确认处（运营台或 dr 支付回调）调用：

```typescript
await accrueDistributionCommission({
  productLine: 'xingxuan',
  subjectType: 'xingxuan_pr', // or talent
  subjectRegistryId: prUserId,
  verifiedCents,
  paidAt,
})
```
