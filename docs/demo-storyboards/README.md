# 官网投放 · 30s 玩法演示关键帧

用途：导入商家 ERP「短片生成 / 无限画布」作分镜参考，或用剪辑工具按时间轴拼成 30s 投放片。  
画幅：16:9 · 单片目标时长：30 秒 · 每镜约 5 秒。

---

目录：`canvas-30s/`

| 时段 | 文件 | 画面 | 口播 |

| 0–5s | `canvas-01-open.png` | 打开无限画布，镜头卡片铺在网格上 | 本地生活短片，先在无限画布里排镜头。 |

### 片 A · 可粘贴执导文案（Seedance / 短片台）

```
【官网投放 30s · 无限画布玩法】
画幅 16:9。产品演示风，干净青色 SaaS 界面，禁止花哨字幕特效。
0-5秒：软件界面推近，无限画布网格与镜头卡片清晰可见。
5-10秒：光标点击「新增镜头」，第三张卡片弹出。
10-15秒：镜头底部素材条出现多张缩略图（图+视频）。
15-20秒：从镜1右侧圆点拖出青色连线到镜2。
20-25秒：点击「应用流程」，连线顺序高亮。
25-30秒：切到画布与短片工作区同屏，收束品牌感。
口播见分镜表；画面内不要烧制大字标题。
```

## 建议成片方式

1. 打开商家 ERP → AI 智能体 → 短片生成 / 无限画布  
2. 将对应目录 6 张图按顺序设为「分镜参考」或镜头素材  
3. 粘贴上方执导文案 → AI 规划分镜（或手动对齐 0-5 / 5-10 …）→ 生成  
4. 官网投放若需竖版，用同一套关键帧改 9:16 再出一版
