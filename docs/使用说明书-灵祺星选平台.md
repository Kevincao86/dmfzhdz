# 灵祺星选平台（Web）使用说明书

**版本：** 2026-06  
**访问地址：** [https://dr.mofangdianai.com](https://dr.mofangdianai.com)  
**适用产品：** 灵祺达人履约管理后台 / 灵祺星选 Web 端  

---

## 1. 产品简介

灵祺星选 Web 平台是达人撮合业务的 **PC / 浏览器端**，与微信小程序「灵祺星选」数据互通。面向两类核心用户：

| 角色 | 典型用户 | 核心能力 |
|------|----------|----------|
| **PR 版** | 品牌 PR、MCN 运营、代运营 | 发招募、审报名、转发工具、模版、发单管理 |
| **达人 / 团队版** | 达人、拍摄团队、剪辑团队 | 招募大厅、AI 推荐、站内报名、我的报名 |

同一账号登录后可切换 **PR** 与 **达人 / 拍摄 / 剪辑** 工作身份（左侧栏底部「身份切换」）。

---

## 2. 运行环境

| 项目 | 要求 |
|------|------|
| 浏览器 | Chrome、Edge、Safari 近期版本 |
| 网络 | 访问 `dr.mofangdianai.com` 及 ECS API |

---

## 3. 注册与登录

1. 打开首页，点击 **登录 / 注册**。  
2. 新用户完成注册并选择初始身份（达人或 PR）。  
3. 登录后自动进入 **招募大厅**；左侧显示当前版本（如「PR 版 · 微信昵称」）及绑定的 **灵祺 ID**。  
4. **退出登录** 会清除本机缓存的报名与消息，避免账号串数据。

## 5. 招募大厅

1. 进入 **招募大厅**，使用顶部分类、平台、城市、预算等筛选。  
2. **急单** 标签展示时效紧缺的单子。  
3. **推荐 Tab**（达人侧）按 AI 匹配分排序，需先完善 `/profile/talent` 或供应商资料页。  
4. 点击卡片进入 **招募详情** `/recruitment/:id`。

---

## 6. 招募详情与报名

详情页展示封面、正文、要求、截止时间、PR 公开信息等。

### 6.1 普通招募

点击 **立即报名** → 跳转 `/recruitment/:id/apply` 填写表单 → 提交后在 **我的报名** 查看状态。

### 6.2 转单招募（Form Relay）

由 **转发工具** 发布的单子标记为转单：

- 按钮文案为 **「前往原表报名」**（非「立即报名」）。  
- 点击在新窗口打开 HTTPS 原表链接（腾讯文档、飞书等）。  
- 若为小程序 scheme 链接，Web 端会提示复制后在微信中打开。  
- 详情正文中 **不展示** 可点击的原表链接行，避免与按钮重复。

---

## 7. PR：发布招募

路径：**发布招募** `/publish`

1. 选择招募目标：达人 / 拍摄团队 / 剪辑团队。  
2. 填写标题、平台、城市、预算区间、详情 Markdown 正文。  
3. 上传 **封面海报**（建议横版或竖版高清图，分享时会裁成 5:4）。  
4. 关联报名表模版（达人 / 拍摄 / 剪辑模版）。  
5. 设置截止时间、是否急单等选项后 **发布**。  
6. 发布成功后同步至小程序招募大厅。

---

## 8. PR：我的发单

路径：**我的发单** `/orders`

| 操作 | 说明 |
|------|------|
| 查看列表 | 按状态筛选进行中 / 已结束 |
| 报名管理 | `/orders/:id/applicants` 审核、通过、拒绝 |
| 视频审核 | `/orders/:id/video-review` 成片回传审核（如启用） |
| 数据概览 | 浏览、报名、转化统计 |

---

## 9. 转发工具

路径：**转发工具** `/form-relay`

适用场景：你已在腾讯文档 / 飞书 / 金数据等维护报名表，希望借助灵祺流量分发，但 **报名仍走原表**。

**操作流程：**

1. 粘贴 **原表链接**（必填）。  
2. 填写或 AI 解析招募标题、正文摘要；**备注框** 可写补充说明（已加大输入区域）。  
3. 点击 **预览**：在预览卡片上 **直接编辑** 标题、正文后再发布（无需「返回修改」流程）。  
4. 确认 **重新预览** 或直接 **发布**。  
5. 生成站内招募单；达人侧显示「前往原表报名」。  
6. 后续可在工具内 **导出** 数据辅助回填原表。

## 10. 我的模版

路径：**我的模版** `/templates`

- 为达人、拍摄、剪辑分别维护报名表字段。  
- 支持字段类型：文本、数字、多行文本、日期、时间、地区等。  
- 内置字段：平台昵称、账号、粉丝数、微信、报价、探店日期等。  
- 编辑页 `/templates/edit` 拖拽排序、锁定必填项。

发招募时选择对应模版，达人报名页自动渲染。

## 13. 与小程序的关系

| 能力 | Web | 小程序 |
|------|-----|--------|
| 招募浏览 / 报名 | ✓ | ✓ |
| PR 发单 / 审报名 | ✓ | ✓ |
| 转发工具 | ✓ | ✓（我的 → 转发工具） |
| 微信分享卡片 | — | ✓（5:4 封面） |
| 外部原表 web-view | 新窗口打开 | 业务域名内嵌或复制引导 |

建议 PR 在 PC 端发单、审报名；达人日常使用小程序浏览与分享。

## 15. 常见问题

**Q：Web 详情页转单仍显示「立即报名」？**  
A：请部署最新 Web 包；转单应显示「前往原表报名」并 `window.open` 原表 HTTPS 链接。

**Q：转发工具预览能否改字？**  
A：可以。预览区支持 inline 编辑，改完后点「重新预览」或直接发布。

**Q：帮助文档在哪？**  
A：站内 `/help` 或本文档 `docs/使用说明书-灵祺星选平台.md`。
