## 二、个人申请 vs 公司申请（你现在选个人）

| 项目 | 个人申请 | 公司申请（以后） |
|------|----------|------------------|
| 著作权人 | 您的真实姓名 + 身份证号 | 公司全称 + 统一社会信用代码 |
| 身份证明 | 身份证正反面扫描件 | 营业执照副本（盖章） |
| 权利归属 | 个人享有 | 公司享有 |
| 软件名称 | 可含「灵祺AI智能ERP」 | 同上 |
| 后期变更 | 公司注册后可办**转让登记** | — |

**注意：**
- 个人名义登记的软件，后续融资、投标、高新认定时，部分场景更认「公司持有」；公司下来后建议尽快做转让。
- 若使用他人代码或开源组件，须在材料中如实说明，避免权属纠纷。

## 五、材料准备清单

### 1. 源代码 PDF

```bash
cd "/Volumes/大魔王的OS/Users/damowangOS/灵祺AI智能ERP/灵祺/项目"

```

输出目录：`docs/软著登记/exports/<产品id>/`

| 文件 | 用途 |
|------|------|
| `01-源码-前30页.txt` | 转 PDF 上传 |
| `02-源码-后30页.txt` | 与上合并为一个 PDF 或分两个上传（按系统要求） |
| `meta.json` | 行数、页数统计（填表用） |

**排版要求（Word）：**
- 页眉：**软件全称 + 版本号**（每页）
- 正文：宋体或 Courier，小四或五号
- **每页不少于 50 行**（与脚本一致）
- 合并为 **一份 PDF** 上传（多数情况要求前 30 + 后 30 连续页码）

### 2. 文档 PDF（用户手册或设计说明书）

使用同目录下：

- `用户手册-灵祺AI智能ERP商家管理系统-V1.0.md`（**已扩写 v1.1**）
- `用户手册-灵祺达人招募小程序软件-V1.0.md`

操作：Markdown → Word → 插入系统截图 → 同样 **前 30 页 + 后 30 页** → PDF。

### 3. 身份证明

- 身份证**正反面**清晰彩色扫描件（JPG/PDF）

### 4. 其他

- 在线签章（部分省市需邮寄纸质材料，以系统提示为准）
- 缴费：支付宝/银行，保留电子票据

## 六、提交后流程

1. 填报 → 上传源码 PDF + 文档 PDF + 身份证  
2. 在线缴费  
3. 形式审查（约 30–60 个工作日，普通通道）  
4. 发放**电子登记证书**（可打印）  

---

## 七、公司注册后如何转给公司

1. 登录 register.ccopyright.com.cn  
2. 办理 **软件著作权转让登记**  
3. 准备：转让合同、双方身份证明、原证书  
4. 建议找代理或按系统模板填写「计算机软件著作权转让合同」
