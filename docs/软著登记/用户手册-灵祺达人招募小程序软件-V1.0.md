## 1. 引言

### 1.1 编写目的

本手册说明「灵祺达人招募小程序软件 V1.0」（以下简称「本小程序」）的安装、配置、功能及操作流程，供达人用户与运营人员参考。

### 1.2 软件概述

本小程序是灵祺 AI 智能 ERP 生态的达人端应用，运行在微信平台。达人可通过本小程序浏览商家发布的探店/云剪招募订单、注册灵祺达人会员资料、提交报名、确认接收云剪成片、回传抖音发布链接并完成结算流程。数据与商家 ERP 及运营管理平台实时同步。

### 1.3 业务形态

| 模式 | 说明 | 达人操作 |
|------|------|----------|
| 开环探店招募 | 商家发布探店需求，达人报名后由运营反选 | 浏览大厅 → 查看详情 → 填写报名表 |
| 急单大厅 | 时效紧缺的招募订单 | 在「急单」标签下优先展示 |
| 云剪闭环 | 商家提供成片，达人确认接收后发布 | 确认/拒绝 → 下载成片 → 回传抖音链接 → AI 核查 |

### 1.4 术语说明

| 术语 | 说明 |
|------|------|
| MP 招募单 | 运营台生成的小程序侧招募订单编号 |
| 商家订单 | ERP 侧原始达人招募订单，与 MP 单关联 |
| 灵祺达人会员 | 在本小程序注册的达人档案，含多平台账号信息 |
| 云剪 ICE | 闭环云剪任务，含成片派发与发布回链 |

## 2. 运行环境

### 2.1 客户端

- 微信客户端：iOS / Android 最新稳定版  
- 微信基础库：建议 2.30.0 及以上  
- 网络：需访问 HTTPS 商家 ERP API 域名  

### 2.2 服务端依赖

- 灵祺商家 ERP 云端 API（`/api/meoo-ops-*` 系列接口）  
- 运营 registry 快照（Supabase `ops_registry_snapshot`）  

### 2.3 开发者本地调试

1. 复制 `utils/config.local.example.js` 为 `utils/config.local.js`  
2. 设置 `MERCHANT_API_BASE_URL` 为本地或测试 ERP 地址  
3. 微信开发者工具打开项目目录，勾选「不校验合法域名」

## 3. 安装与打开

### 3.1 用户端

1. 微信搜索小程序名称或扫描运营分享的小程序码  
2. 首次打开进入招募大厅首页  
3. 若提示未配置后台，请联系运营检查 API 域名  

### 3.2 分享进入详情

运营在「商家达人招募订单」选择小程序招募后，分享路径格式为：

```
pages/detail/detail?id={MP招募单号}
```

达人点击分享卡片可直接进入该招募详情页。

## 4. 达人会员注册

### 4.1 入口

- 招募大厅顶部「注册 / 完善资料」按钮  
- 路径：`pages/register/register`  

### 4.2 填写项说明

| 字段 | 说明 |
|------|------|
| 微信昵称/头像 | 自动或手动填写 |
| 达人类型 | 如探店、云剪等分类 |
| 联系方式 | 手机号等 |
| 微信号 | 便于商家联系 |
| 所在省市 | 省市区二级联动选择 |
| 抖音资料 | 账号、昵称、主页链接、粉丝数、带货等级、报价、支付宝 |
| 小红书资料 | 同上（字段标签随平台切换） |

### 4.3 提交与同步

1. 填写完成后点击「提交注册」  
2. 资料写入本地缓存并同步至运营 registry `mpTalentMembers`  
3. 同步至灵祺达人库，供运营筛选  

### 4.4 编辑资料

已注册用户可通过 `register?edit=1` 修改资料，流程与注册相同。

## 5. 招募大厅

### 5.1 页面结构

路径：`pages/index/index`

顶部展示当前达人会员状态；下方为三个标签页：

| 标签 | 内容 |
|------|------|
| 普通招募 | 常规开环探店订单 |
| 急单大厅 | 标记为 urgent 的订单 |
| 云剪任务 | ICE 闭环云剪订单 |

### 5.2 列表字段

每条招募展示：商家名、门店、标题、平台、地区、摘要、已报名人数、状态标签等。

### 5.3 下拉刷新

页面 `onShow` 时自动拉取最新 registry 数据；失败时提示检查网络与 API 配置。

### 5.4 进入详情

点击列表项跳转 `pages/detail/detail?id=xxx`。

【截图占位：招募大厅三标签页】

## 6. 招募详情与报名

### 6.1 详情页

路径：`pages/detail/detail`

展示招募完整要求：佣金、探店时间、内容形式、Brief 摘要、门店地址等（数据来自商家订单 enrichment）。

### 6.2 开环报名流程

1. 在详情页点击「立即报名」  
2. 跳转 `pages/apply/apply`，携带 mp 单号与平台参数  
3. 填写平台账号、粉丝数、报价、可探店日期时段、支付宝等  
4. 若已注册会员，可勾选「同步会员资料」自动填充  
5. 提交后写入报名列表，运营在后台反选达人  

【截图占位：招募详情页】  
【截图占位：报名表单页】

### 6.3 报名校验

- 必填项：平台账号、联系方式、地区等  
- 抖音需选择带货等级 LV0–LV7  
- 缺少 mp 单号时提示错误

## 7. 云剪闭环任务

### 7.1 识别云剪单

详情页 `isIce` 为 true 时进入云剪模式，展示成片信息与确认按钮。

### 7.2 确认接收 / 拒绝

- 调用 API：`/api/meoo-ops-mp-recruitment-ice-confirm`  
- 达人选择「确认接收」或「拒绝」  
- 状态本地缓存 applicantId 便于后续步骤  

### 7.3 下载与发布

1. 确认后展示分配的视频 URL  
2. 达人下载成片并在抖音发布  
3. 在小程序填写抖音作品链接  

### 7.4 回链提交

- 调用 API：`/api/meoo-ops-mp-recruitment-ice-submit`  
- 系统 AI 核查发布链接  
- 通过后进入待结算状态

## 9. 数据同步说明

### 9.1 数据来源

小程序通过 `utils/merchantApi.js` 请求 ERP HTTPS API，读取 `ops_registry_snapshot` 中的：

- `mpRecruitmentOrders`：小程序招募单  
- `recruitmentOrders`：商家原始订单  
- `mpTalentMembers`：达人会员  

### 9.2 状态枚举

| 状态 | 展示 |
|------|------|
| open | 招募中 |
| collecting | 收集中 |
| pending_settlement | 待结算 |
| closed | 已关闭 |
| done | 已完成 |

### 9.3 生产配置

复制 `utils/config.release.example.js` 为 `config.release.js`，填写生产 API 根地址；在微信公众平台配置 request 合法域名。

## 10. 常见问题

**Q1：提示「无法连接后台」？**  
A：检查 `config.local.js` / `config.release.js` 中 API 地址是否正确，生产环境须 HTTPS 且域名已加入微信白名单。

**Q2：招募单不存在？**  
A：订单可能已关闭或 id 错误；请通过运营分享链接重新进入。

**Q3：报名后无反馈？**  
A：开环模式需运营在后台反选；请保持联系方式畅通。

**Q4：云剪无法提交链接？**  
A：确认已「确认接收」且链接为有效抖音作品 URL。
