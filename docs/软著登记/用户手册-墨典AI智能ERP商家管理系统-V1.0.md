## 1. 引言

### 1.1 编写目的

本手册说明「墨典AI智能ERP商家管理系统 V1.0」（以下简称「本系统」）的功能、操作流程及注意事项，供商户及操作人员使用。

### 1.2 软件概述

本系统是一套面向本地生活行业的商户经营管理系统，集成 AI 智能体、多平台门店与商品管理、达人招募、评价与 GEO 运营、投流线索、财务对账等功能，帮助商户实现数字化经营与智能决策。

### 1.3 术语说明

| 术语 | 说明 |
|------|------|
| AI 智能体 | 可理解自然语言并执行创建商品、达人招募等任务的智能助手 |
| 预览确认 | 执行敏感操作前展示预览，用户确认后再调用业务接口 |
| 租户 | 独立商户账号及其数据隔离单元 |
| GEO | 本地搜索与地图场景下的门店曝光优化 |

## 5. AI 智能体

### 5.1 功能说明

AI 智能体支持自然语言描述经营需求，自动识别任务类型并生成**执行预览**，用户确认后调用相应业务接口。

### 5.2 九大快捷场景

| 场景 | 说明 |
|------|------|
| 创建商品 | 生成团购/代金券 C 端预览并保存草稿 |
| 招募达人 | 生成 Brief 与招募订单 |
| 处理评价 | 差评分析与回复建议 |
| 优化本地推 | 投放优化建议 |
| 跟进线索 | 线索跟进策略 |
| 同步平台 | 平台数据同步辅助 |
| 分析异常 | 经营异常诊断 |
| 生成推广文案 | 营销文案生成 |
| 一键报税 | 财务汇总与申报包（会员） |

【截图占位：AI 智能体对话界面】

### 5.3 方案与确认执行

1. 用户描述规划类需求（如「帮我规划下月抖音推广」）  
2. 系统输出完整方案文档  
3. 用户回复「确认执行」  
4. 系统为各场景**分别生成独立预览卡片**  
5. 用户在卡片内确认、修改或取消  
6. 确认后写入草稿或推送运营订单  

### 5.5 对话与附件

- 支持在输入框粘贴或上传**图片、视频**；视频会自动提取首帧供模型理解  
- 支持引用当前页面上下文（如在商品页打开 AI 抽屉时带入页面信息）  
- 可随时点击「停止生成」中断长回复  

### 5.6 创建商品场景详细步骤

**步骤 1：** 点击快捷任务「创建商品」或输入「帮我上架一个双人套餐」。  
**步骤 2：** AI 返回方案或 JSON 预览，若含 `confirmRequired` 需回复「确认执行」。  
**步骤 3：** 系统生成 C 端手机预览卡片（可多套餐并列），展示标题、价格、套餐项、主图。  
**步骤 4：** 逐项核对；若无商品图可回复「自动生成」。  
**步骤 5：** 点击卡片「确认」，系统写入各平台**草稿箱**。  
**步骤 6：** 进入商品编辑页选择类目、门店后提交平台审核。  

【截图占位：创建商品预览卡片确认】

### 5.7 达人招募场景详细步骤

**步骤 1：** 描述招募需求，或通过 AI 在组品方案后执行招募。  
**步骤 2：** 系统生成三版 Brief 预览，展示主推品、标签与文案。  
**步骤 3：** 确认 Brief 后自动生成招募订单并推送运营台（待接单）。  
**步骤 4：** 在「达人招募 → 查看订单」查看进度；运营接单后进入达人池与排期。  

【截图占位：Brief 三版预览】

### 5.8 分析异常场景详细步骤

**步骤 1：** 点击快捷任务「分析异常」。  
**步骤 2：** AI 基于 GEO、评价、商品毛利等维度输出诊断方案。  
**步骤 3：** 回复「确认执行」后生成**分析异常**独立预览（不会误提示创建商品/招募）。  
**步骤 4：** 在预览卡片确认后查看结构化分析结果。  

### 5.9 多场景并行规则

当方案同时包含「组品上架」与「达人招募」时：

- 须先用户回复「确认执行」  
- 各场景生成**独立预览卡片**，不可合并  
- 用户分别确认后才会调用对应接口  
- 商品创建完成后 AI 会引导是否继续达人招募  

### 5.10 会话与归档

- 支持新建对话、查看历史归档  
- 切换对话不丢失未确认预览状态（同一会话内）  
- 会员档位决定可用模型数量与功能权限

## 5A. AI 智能体 — 九大场景操作说明（详）

### 5A.1 创建商品

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 输入需求或点快捷任务 | AI 理解餐型/代金券/组品 |
| 2 | 确认方案 | 出现预览卡片 |
| 3 | 核对 C 端样式 | 标题、价、图、套餐项正确 |
| 4 | 确认 | 草稿箱出现记录 |

### 5A.2 招募达人

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 说明平台、预算、时间 | AI 生成 Brief |
| 2 | 选择 Brief 版本 | 确认后生成订单 |
| 3 | 查看订单卡片 | 显示 AI 档位分配 |

### 5A.3 处理评价

支持导入差评内容，AI 给出原因分析与回复话术建议；确认后可复制至平台回复。

### 5A.4 优化本地推

读取绑定投放账户摘要，给出出价、定向、创意优化建议预览。

### 5A.5 跟进线索

对本地推线索列表生成跟进优先级与话术建议。

### 5A.6 同步平台

辅助排查商品/门店同步失败原因与修复步骤。

### 5A.7 分析异常

综合多数据源输出异常诊断与改进方案（见 5.8）。

### 5A.8 生成推广文案

按行业与活动节点生成短文案、话题词、口播稿等。

### 5A.9 一键报税

汇总各绑定平台核销数据，生成报税预览与导出包（会员）。

## 7. 商品管理

### 7.1 商品列表

查看各平台商品/团购/代金券状态，支持筛选与跳转编辑。

### 7.2 创建商品

1. 选择平台（如抖音来客）  
2. 填写类目、门店、套餐项、价格、图片  
3. 保存草稿或提交审核  

### 7.3 AI 创建流程

通过 AI 智能体生成方案 → 预览 C 端手机效果 → 确认后保存至商品草稿箱 → 在编辑页补全类目与门店后提交。

### 7.4 商品编辑流程

1. 从列表进入 `/products/edit/{platform}/{productId}`  
2. 修改套餐组、价格、库存、适用门店  
3. 上传或 AI 生成主图/辅助图  
4. 保存草稿或提交审核  

### 7.5 多平台商品

支持抖音来客、快手、小红书、美团等（依绑定情况）；各平台表单字段按平台规范动态展示。

### 7.6 代金券与团购

- **团购套餐** productType=1：含套餐项组合  
- **代金券** productType=2：面额、代金规则、适用规则  

AI 组品可解析「主套餐 / 次套餐 / 赠品策略」分别生成预览。

## 8. 运营中心

### 8.1 达人招募

- **发布招募需求**：新手版 / 专业版  
- **AI Brief 生成**：三版文案可选  
- **查看订单**：展示最近 AI/手动提交的招募订单及进度  
- 流程：发布 → AI 达人池 → 排期 → 视频审核 → 结款  

### 8.1.1 新手版招募

填写：城市、行业、套餐说明、总预算、招募/探店时间；AI 自动按同城达人成本输出 V3/V4/V5/V5+ 人数档位。

### 8.1.2 专业版招募

完整配置：平台、内容形式、佣金率、门店、达人标签、粉丝层级、预算、Brief 等。

### 8.1.3 Brief 向导

1. 选择 Brief 行业标签  
2. AI 生成三版 Brief  
3. 选择版本写入招募单  

### 8.1.4 招募流程五阶段

| 阶段 | 说明 |
|------|------|
| 发布招募需求 | 开环探店或云剪闭环 |
| AI 达人池筛选 | 星图匹配、替换确认 |
| AI 排期编排 | 按门店产能排期 |
| 视频审核管理 | 审核成片、反馈修改 |
| 结款账单 | 确认结款与账单 |

### 8.1.5 查看订单

展示最近一次提交的招募订单号、状态、进度步骤；支持手动刷新；AI 智能体确认后自动写入并刷新。

## 12. 系统架构与安全（设计说明）

### 12.1 总体架构

本系统采用**浏览器 + 云端 API + 数据库**三层架构：

- **表现层：** React SPA，路由驱动各业务模块  
- **业务层：** Vercel Serverless Functions，封装平台 OpenAPI 与 AI 调用  
- **数据层：** Supabase PostgreSQL，多租户隔离存储  

【示意图占位：系统架构图】

### 12.2 多租户隔离

- 每个商户对应独立 `tenantId`  
- 本地缓存键带租户后缀，防串号  
- 运营 registry 按租户过滤读写  

### 12.3 认证与授权

- Supabase Auth 手机号/邮箱登录  
- JWT 访问 API；服务端校验租户归属  
- 会员计划控制功能可见性  

### 12.4 AI 调用安全

- 商户可选自带 LLM API Key  
- 预览确认前不写入生产平台  
- 敏感操作需用户显式点击确认

## 14. 常见问题（扩展）

**Q1：预览一直加载？**  
A：检查网络与 AI 模型配置；可刷新页面或新建对话重试。

**Q2：商品无法提交审核？**  
A：确认已在商品编辑页选择类目、门店并完成必填项。

**Q3：招募订单在运营台看不到？**  
A：确认已登录正确租户；订单推送需网络与云端服务正常。

**Q4：如何联系客服？**  
A：点击右下角在线客服浮窗。

**Q5：切换账号后数据错乱？**  
A：系统会在切换租户时清理本地缓存，请重新登录同一商户账号。

**Q6：AI 预览数量与方案不一致？**  
A：组品方案须含清晰「主套餐/次套餐/赠品策略」结构；可新建对话重试。

**Q7：飞书未收到招募订单通知？**  
A：属运营侧配置，需管理员配置 Webhook 环境变量。

**Q8：免费版与 Plus 区别？**  
A：Plus 可用全部 AI 模型、GEO、竞对、报税等；详见会员说明页。

**Q9：商品主图不清晰？**  
A：上传更高分辨率菜品图，或让 AI 按品类重新生成。

**Q10：招募「查看订单」为空？**  
A：确认已在 AI 或招募页成功提交；点击刷新；检查是否同一租户。

**Q11：平台绑定后刷新丢失？**  
A：确认 Supabase 在线；勿在离线态清缓存。

**Q12：Excel 菜单导入失败？**  
A：检查列名与模板一致，去除合并单元格。

**Q13：子账号无法访问模块？**  
A：主账号在子账号权限中勾选对应菜单。

**Q14：视频 AI 处理超时？**  
A：缩短视频时长或检查 ICE 服务配额。

**Q15：如何归档 AI 对话？**  
A：在 AI 智能体侧栏使用归档功能，便于后续查阅。
