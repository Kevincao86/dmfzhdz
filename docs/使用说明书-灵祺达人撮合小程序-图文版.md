## 图 1 · 产品总览

灵祺星选小程序是微信端的达人撮合入口。底部五个 Tab 覆盖 **找单 → 匹配 → 发单 → 沟通 → 管理** 全链路。

![小程序总览](manual-assets/manual-mp-overview.png)

| Tab | 你能做什么 |
|-----|------------|
| 首页 | 浏览全部招募、急单、筛选 |
| 推荐 | AI 按你的资料匹配招募 |
| 发招募 | PR 发布新单子 |
| 消息 | 与 PR 聊天 |
| 我的 | 资料、报名、模版、转发工具 |

## 图 2 · 四种工作身份

同一微信账号可切换身份，菜单自动变化：

| 身份 | 图标 | 典型场景 |
|------|------|----------|
| 达人 | 🎭 | 抖音/小红书探店、带货 |
| 拍摄团队 | 📷 | 商拍、活动跟拍 |
| 剪辑团队 | ✂️ | 短视频剪辑、云剪 |
| PR | 💼 | 品牌发单、审报名 |

**操作：** 我的 → 顶部身份标签 → 选择身份 → 完善对应资料页。

## 图 3 · 找单与分享（无黑边海报）

![详情与分享](manual-assets/manual-mp-apply-share.png)

### 达人找单三步

1. **首页 / 推荐** 点开招募卡片  
2. **详情页** 查看要求、AI 匹配分、截止时间  
3. 点击 **立即报名** 填写表单，或 **前往原表报名**（转单）

### 分享招募

- 详情页右上角分享给好友 / 群 / 朋友圈  
- 封面自动 **5:4 居中裁剪铺满**，避免微信卡片上下黑边  
- 标题同步为招募标题

## 图 4 · PR 发单流程

```
发招募 Tab → 填标题/平台/预算/封面 → 选报名表模版 → 发布
     ↓
我的发单 → 查看报名 → 审核通过/拒绝
     ↓
（可选）视频审核 / 消息通知达人
```

### 转发工具（外部表单转单）

**我的 → 转发工具**

1. 粘贴腾讯文档等原表链接  
2. 写备注，预览并可 **直接改标题正文**  
3. 发布后在站内展示，达人点「前往原表报名」回你的原表

## 图 6 · 常见问题速查

| 现象 | 处理 |
|------|------|
| 分享海报有黑边 | 更新最新体验版（含 share-cover-fill 构建） |
| 原表打不开 | 先登录；非白名单域名用复制链接页 |
| 推荐为空 | 完善平台粉丝、城市、品类 |
| 与 Web 不同步 | 确认同一账号登录 ECS 数据面 |
