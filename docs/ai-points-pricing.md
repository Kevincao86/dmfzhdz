# AI 积分消耗与 60% 毛利定价

权威源码：`web版/merchant-erp/src/lib/mpPointsEconomics.ts`、`erpPointsEconomics.ts`。

## 计价模型

| 参数 | 值 | 说明 |
|------|-----|------|
| 内部成本 | 1 积分 = ¥0.01 API 成本容量 | 消耗积分 ≈ API 成本(元) × 100 |
| 目标毛利率 | **60%** | 用户支付价中 40% 覆盖 AI 成本 |
| 充值换算 | **¥1 = 40 积分** | 原 50 积分（50% 毛利）已下调 |
| 用户实付 | 消耗积分 ÷ 40（元） | 毛利 ≈ (实付 − API成本) / 实付 |

## 扣减链路

| 产品 | 账本 | 入口 |
|------|------|------|
| 星选 / 达人撮合小程序 | mp 注册表双桶 | `POST /erp-api/meoo-ops-mp-auth` · `mp_ai_points_afford` / `mp_ai_points_spend` |
| 商家 ERP / 服务商 fws | `tenants.erp_*_points` | `POST /erp-api/meoo-tenant-billing` · `points_check` / `points_spend` |
| 服务商映射星选账号 | 改扣 ERP 桶 | `partnerXingxuanBilling` |

原则：凡调用 LLM / 生图 / 视频 AI 成功，服务端或客户端须扣积分；余额不足返回 **402**。
