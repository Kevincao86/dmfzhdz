## 需求一：PR 视频审核 · 外部分享标注页

### 背景

PR 在「待视频审核」阶段需将达人成片发给客户、品牌方或协作同事审片。当前仅 PR 登录后在小程序 / Web 履约后台内审核，外部人员无法便捷标注问题点。

### 目标

1. 在 **待视频审核** 页面为每条招募单增加 **「生成分享页」** 入口。
2. 分享页 **无需登录**，仅可 **查看视频** + **在视频上添加/编辑标注框** + **填写问题点评论**。
3. 外部分享页产生的标注与评论，**实时同步** 至 PR 端「待视频审核」订单内，对应视频卡片下方空白区域展示。
4. **Web 履约后台**（`灵祺达人履约管理后台`）逻辑与小程序 PR 端 **完全一致**（同一分享 token、同一 API、同一数据）。

### 涉及端

| 端 | 现有入口 | 新增页面 |
|----|----------|----------|
| 达人撮合小程序 · PR | `pages/mine-pr-order-video-review` | 分享按钮；外链 H5 / 小程序分享卡片 |
| 达人撮合小程序 · 外链 H5 | — | 公开分享审片页（建议独立 H5，也可 WebView） |
| 达人履约 Web | `/orders/:id/video-review` | 分享按钮 + 外部分享页（同 H5） |
| 轻量 API | — | 分享 token、标注 CRUD、评论同步（**待开发，本文档仅定义**） |

### 页面清单

| 编号 | 页面 | 路由（建议） | 权限 | 核心功能 |
|------|------|--------------|------|----------|
| share-01 | PR · 待视频审核（增强） | 小程序 `mine-pr-order-video-review?id=` / Web `/orders/:id/video-review` | PR 登录 | 顶部新增「分享审片」；展示外部分享链接/二维码；各视频下方展示 **外部分享评论汇总区** |
| share-02 | 外部分享审片页 | `/public/video-review-share/:token`（H5） | **无需授权** | 只读视频列表；每视频播放器 + 可拖拽 **标注框**；标注关联 **时间点 / 画面区域**；问题点文字评论 |
| share-03 | 标注编辑浮层 | share-02 内 Modal | 无需授权 | 新建/编辑标注：框选区域、选帧时间、问题描述、严重程度（可选） |

### 交互规则

#### 分享生成（PR 端）

- PR 点击「分享审片」→ 后端生成 **单次招募单级 shareToken**（可配置有效期，默认 7 天，可手动失效）。
- 输出：复制链接、生成二维码、微信分享（小程序 `onShareAppMessage` 指向 H5 或中间跳转页）。
- 分享页 **不可** 执行通过/驳回/下载源片等 PR 特权操作。

#### 外部分享页（访客）

- 打开链接即可访问，**不收集微信授权**；可选填写 **访客昵称**（localStorage 记忆，默认「访客 xxx」）。
- 每个达人视频卡片：
  - 视频播放器（仅播放，无下载按钮）。
  - 画面上叠加 **标注框**（矩形框，颜色区分不同访客或问题类型）。
  - 点击空白处或「+ 添加标注」→ 框选区域 + 填写问题点。
  - 已有标注可点击编辑/删除（仅创建者 24h 内可删，或 PR 端可删全部——待产品确认，原型默认均可编辑）。
- 提交后写入服务端，PR 端 **轮询或 WebSocket** 刷新评论区。

#### PR 端评论展示（待视频审核 · 视频卡片下方）

- 在现有「通过 / 驳回」按钮 **下方** 增加 **「外部分享反馈」** 区块（现有空白区域）：
  - 按视频分组，列出：标注缩略图 / 时间点、问题描述、访客昵称、提交时间。
  - PR 可「标记已处理」；**不影响** 现有审核通过/驳回流程。
- Web 与小程序展示字段、排序规则一致。

## 需求二：运营管控台 · 账号权限细化（查看/编辑 + 省市数据范围）

### 背景

运营管控台（`admin.mofangdianai.com`）「账号与权限」当前为 **模块级勾选**（有/无），无 **查看 vs 编辑** 区分，也无法按 **省/市** 限制子账号可见数据（如省代、市代）。

### 目标

1. 每个功能模块拆分为 **「查看」** 与 **「编辑」** 两项权限；**仅「编辑」** 方可增删改、审核、导出等写操作。
2. 新增 **数据可见范围**：按 **省份**、**城市** 分配；子账号仅能看到归属范围内数据。
3. 主账号（超级管理员）仍为 **全部模块 + 全部省市 + 编辑**。
4. 列表页（如 PR 用户库、灵祺达人库）的省/市筛选项与数据行 **自动受数据范围约束**。

### 涉及端

| 端 | 现有页面 | 变更类型 |
|----|----------|----------|
| 运营管控台 | `/accounts-permissions` `OpsAccountsPermissionsPage` | **增强** 创建/编辑子账号表单 |
| 运营管控台 · 各业务列表 | 如 `/pr-library`、`/talent-library` 等 | **增强** 读路径加 scope 过滤；写操作校验 edit 权限 |
| 数据库 | `ops_staff_accounts.permissions` jsonb | **扩展** 结构（见下） |
| 轻量 API | ops staff CRUD | **扩展** 校验逻辑（待开发） |

### 页面清单

| 编号 | 页面 | 路由 | 核心功能 |
|------|------|------|----------|
| perm-01 | 账号与权限（增强） | `/accounts-permissions` | 子账号表格增加「权限摘要」「数据范围」列 |
| perm-02 | 创建/编辑子账号弹窗 | perm-01 内 Modal | 模块矩阵：**查看 ☑ / 编辑 ☑**；数据范围：**全国 / 指定省 / 指定省+市** |
| perm-03 | 数据范围选择器 | perm-02 内 | 省多选 → 市多选（级联）；支持「全省可见」快捷 |
| perm-04 | 业务页 · 只读态示例 | `/pr-library` | 仅有「查看」时：隐藏批量开通、编辑按钮；筛选仍可用但在 scope 内 |
| perm-05 | 业务页 · 无权限拦截 | 任意模块 | 无「查看」→ 菜单不可见或跳转无权限页 |

### 权限矩阵（模块 × 查看/编辑）

沿用现有 `OPS_PERMISSION_MODULES` 模块列表，每项扩展为：

```json
{
  "moduleKey": "pr_library",
  "canView": true,
  "canEdit": false
}
```

**规则**

- `canEdit === true` 隐含 `canView === true`（勾选编辑时自动勾选查看）。
- 取消查看时自动取消编辑。
- 写操作 API（POST/PATCH/DELETE、批量开通、审核通过等）服务端校验 `canEdit`。
- 读操作 API（GET、列表、导出预览）校验 `canView` + **dataScope**。

### 数据可见范围（dataScope）

```json
{
  "mode": "national" | "provinces" | "cities",
  "provinces": ["浙江省", "江苏省"],
  "cities": ["杭州市", "金华市"]
}
```

| mode | 说明 | 典型角色 |
|------|------|----------|
| `national` | 全国数据 | 总部运营 |
| `provinces` | 仅所列 **省份** 内记录 | 省代 |
| `cities` | 仅所列 **城市** 内记录（可跨省） | 市代 |

**过滤字段**（与 PR 用户库、达人库现有列对齐）：

- 达人/PR 库：`province`、`city`（及注册地、常驻地等已有字段，以实现时库表为准）。
- 订单类：按达人/商家 **归属省市** 或订单 **执行城市** 过滤（模块实现时映射具体字段）。

**UI 表现**

- 子账号登录后，列表页省/市 Tab **仅展示 scope 内选项**；不可切换到 scope 外。
- 表格数据 SQL/API 层强制 `WHERE province IN (...) AND city IN (...)`，防前端绕过。

### 与现有功能边界

| 现有能力 | 本需求 |
|----------|--------|
| 主账号全权限 | **不变** |
| 子账号模块勾选 | **升级为** 查看/编辑双列 |

| 菜单可见性 | **增强**：无查看权限的模块 **侧栏隐藏** |
