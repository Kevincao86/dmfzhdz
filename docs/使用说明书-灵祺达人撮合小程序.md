# 灵祺星选 · 达人撮合小程序 使用说明书

**版本：** 2026-06  
**适用产品：** 微信小程序「灵祺星选」（灵祺达人撮合小程序）  
**访问方式：** 微信搜索小程序或扫描 PR / 运营分享的招募卡片进入  

---

## 1. 产品简介

灵祺星选达人撮合小程序是灵祺 AI 智能 ERP 生态的**移动端入口**，连接 PR、商家与内容供给方（达人、拍摄团队、剪辑团队）。你可以在手机上完成：

- 浏览、筛选、收藏招募单  
- 查看 AI 匹配度与推荐理由  
- 一键报名（站内表单或跳转外部原表）  
- PR 发布招募、管理报名、使用转发工具  
- 消息沟通、通知、数据分析  

同一微信账号可在 **达人 / 拍摄团队 / 剪辑团队 / PR** 四种工作身份间切换，菜单与功能随身份变化。

## 3. 首次使用

### 3.1 欢迎页与身份选择

首次打开进入欢迎页，选择你的工作身份：

| 身份 | 适用人群 | 系统 ID |
|------|----------|---------|
| 达人 | 抖音/小红书等平台内容创作者 | 灵祺达人 ID |
| 拍摄团队 | 探店、活动、商拍等拍摄承接方 | 拍摄团队 ID |
| 剪辑团队 | 短视频剪辑、云剪承接方 | 剪辑团队 ID |
| PR | 品牌方、MCN、代运营发单 | 灵祺 PR ID |

### 3.2 微信登录

点击「微信登录」授权昵称与头像。未登录可浏览招募大厅部分列表，**报名、发单、消息**等需登录后使用。

### 3.3 完善资料

进入 **我的 → 我的信息 / PR 信息 / 团队信息**，填写：

- **达人：** 多平台昵称、粉丝量、带货等级、城市、联系方式等  
- **拍摄 / 剪辑团队：** 团队名称、设备、风格、日产能、作品集链接  
- **PR：** 机构名称、所在城市、联系方式  

资料越完整，首页 **推荐 Tab** 的 AI 匹配越准确。

---

## 4. 底部导航（五大 Tab）

| Tab | 功能 |
|-----|------|
| **首页** | 招募大厅：全部招募、急单、筛选（平台/城市/预算等） |
| **推荐** | 基于你的资料 AI 匹配的招募列表与匹配分 |
| **发招募** | PR 身份：发布新招募单（达人/拍摄/剪辑目标可选） |
| **消息** | 会话列表，与 PR 或系统通知相关沟通 |
| **我的** | 资料、报名/发单、模版、转发工具、通知、数据分析、客服 |

未登录时「发招募」等入口会引导登录。

---

## 5. 达人 / 团队侧：找单与报名

### 5.1 浏览招募大厅

1. 打开 **首页**，上下滑动浏览招募卡片。  
2. 点击卡片进入 **招募详情**。  
3. 详情页展示：封面海报、标题、平台、预算、探店/拍摄要求、截止时间等。  
4. 系统会显示 **AI 匹配分**（若已完善资料）。

### 5.2 立即报名

- **普通招募单：** 点击「立即报名」，填写报名表（字段由 PR 模版决定，常见：平台账号、粉丝数、报价、探店日期等）。  
- **转单招募（外部表单代收）：** 按钮为「**前往原表报名**」。需先登录，再跳转腾讯文档等外部链接；若域名未配置 web-view，会进入复制链接引导页。  
- 详情正文中的「原表链接」文字已隐藏，仅通过按钮跳转，避免误点。

### 5.3 我的报名

**我的 → 我的报名** 查看已提交记录及状态（待审核 / 已通过 / 未通过等）。

### 5.4 分享招募

在详情页点击右上角「…」或页面分享按钮：

- 分享给好友 / 群：生成微信卡片，标题为招募标题，封面为 **5:4 铺满海报**（系统自动裁剪，无上下黑边）。  
- 分享到朋友圈：同步使用裁剪后的本地封面图。

## 6. PR 侧：发单与管理

### 6.1 发布招募

1. 切换到 **PR 身份**（我的页顶部切换）。  
2. 进入 **发招募** Tab 或 **我的 → 我的发单 → 发布**。  
3. 填写标题、目标（达人/拍摄/剪辑）、平台、城市、预算、详情正文、封面图。  
4. 选择报名表模版（可在 **我的模版** 中预先配置）。  
5. 发布后出现在招募大厅，达人端与 Web 星选平台同步展示。

### 6.2 我的发单

**我的 → 我的发单** 管理已发布订单：

- 查看浏览量、报名数  
- 进入 **报名列表** 审核达人  
- **视频审核**（如有成片回传流程）  
- 下架 / 编辑（按订单状态）

### 6.3 转发工具

**我的 → 转发工具** 用于「外部表单转单」场景：

1. 粘贴腾讯文档 / 飞书 / 其他平台招募表链接。  
2. 填写备注、预览并 **可 inline 编辑** 标题与正文后再发布。  
3. 生成灵祺站内招募单，达人点击「前往原表报名」回到你的原表。  
4. 支持导出报名数据回填外部表格。

### 6.4 我的模版

配置达人 / 拍摄 / 剪辑三类报名表字段（文本、数字、日期、地区等），发单时复用。

**我的 → 数据分析** 查看报名数、发单转化等概况（PR 与达人视角字段不同）。

## 9. 身份切换

在 **我的** 页点击当前身份标签，可在达人 / 拍摄 / 剪辑 / PR 间切换。切换后 Tab 与菜单自动更新；每种身份有独立 ID 与资料存储。

## 10. 常见问题

### 10.1 通用

**Q：与 Web 版数据是否一致？**  
A：是。小程序与 `dr.mofangdianai.com` 灵祺星选 Web 共用 ECS 数据面，登录同一账号即可同步。

**Q：如何切换身份？**  
A：「我的」页顶部点击当前身份标签，选择达人/拍摄/剪辑/PR。

### 10.2 达人

**Q：分享卡片海报上下有黑边？**  
A：请更新到最新体验版（构建号含 `share-cover-fill`）。系统会将封面 **居中裁剪为 5:4 铺满**。

**Q：点击「前往原表报名」没反应？**  
A：请先微信登录；外部链接需在小程序业务域名白名单内才能内嵌打开，否则使用复制链接页手动打开。

**Q：推荐页没有匹配结果？**  
A：完善 **我的信息** 中的平台粉丝、城市、品类标签后刷新。

**Q：报名后无反馈？**  
A：PR 需在报名列表审核；保持消息通知开启，或在「小灵同学」咨询。

**Q：云剪直发如何接单？**  
A：云剪任务详情报名 → 确认接收 → 下载成片 → 发布回传链接。

### 10.3 拍摄团队

**Q：接不到拍摄类订单？**  
A：确认拍摄团队身份；完善设备、风格、作品集；筛选拍摄类招募。

**Q：档期冲突怎么办？**  
A：报名前核对 Brief 日期；冲突时通过消息联系 PR。

**Q：视频审核被驳回？**  
A：按 PR 备注修改后重传。

### 10.4 剪辑团队

**Q：云剪任务如何接单？**  
A：报名后确认接收，下载成片，发布并回传链接。

**Q：剪辑任务包条数不足？**  
A：认领 N 条须上传 N 个文件；仅剪辑身份可认领。

**Q：审片驳回如何重传？**  
A：仅重传被驳回的条，对照 Brief 修改。

### 10.5 PR

**Q：转单招募怎么发？**  
A：「转发工具」粘贴原表链接，预览发布；达人显示「前往原表报名」。

**Q：发单后达人看不到？**  
A：确认订单进行中、目标选对、未过截止时间。
