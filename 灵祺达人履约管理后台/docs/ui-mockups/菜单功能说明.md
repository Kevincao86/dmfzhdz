# 灵祺星选平台 · 菜单功能说明

> 本文档供 UI 稿审阅对照使用。代码导航见 `src/lib/shellNavConfig.ts`，身份见 `src/lib/mpWorkIdentity.ts`。

## 身份与侧栏差异

| 身份 | 侧栏菜单 |
|------|----------|
| **PR** | 招募大厅、发布招募、我的发单、转发工具、我的模版、消息、增值服务、我的 |
| **达人** | 招募大厅、我的报名、消息、增值服务、我的 |
| **拍摄团队** | 同达人（工作台身份为拍摄，大厅默认展示拍摄类任务） |
| **剪辑团队** | 同达人（工作台身份为剪辑，大厅默认展示剪辑类任务） |

**共用子页**（从大厅/发单等入口进入，不在侧栏）：招募详情、报名页、私信聊天、PR 资料 / 达人资料 / 团队资料。

---

## PR 版（13 张稿 + 共用）

| 稿图 | 路由 | 功能 |
|------|------|------|
| pr-01 | `/hall?tab=home` | **首页仪表盘**：发单统计、待办提醒、快捷入口 |
| pr-02 | `/hall?tab=hall` | **招募大厅**：浏览全平台在招商单（PR 也可看同行发单） |
| pr-03 | `/hall?tab=recommend` | **推荐大厅·达人库**：按条件筛选达人、发起邀约 |
| pr-04 | `/publish` | **发布招募**：填写标题、平台、预算、封面、需求，发布或存草稿 |
| pr-05 | `/orders` | **我的发单**：已发布/草稿/已停止/已删除 Tab，管理每条招募 |
| pr-06 | `/orders/:id/applicants` | **报名管理**：查看报名人、确认入选、导出、发群码 |
| pr-12 | `/orders/:id/video-review` | **视频审核**：审核达人提交的成片，通过或退回 |
| pr-07 | `/form-relay` | **转发工具**：外链表单转为本平台招募单并分发 |
| pr-08 | `/templates` | **我的模版**：保存常用招募字段，一键复用发布 |
| pr-09 | `/messages` | **消息**：系统通知 + 私信列表（双栏） |
| pr-11 | `/addons` | **增值服务**：会员、加速推荐等付费能力 |
| pr-10 | `/profile` | **我的**：账号入口、统计、设置菜单 |
| pr-14 | `/profile/pr` | **PR 资料**：品牌/机构信息、联系人、案例 |
| pr-13 | `/recruitment/:id` | **招募详情**（只读/编辑入口） |
