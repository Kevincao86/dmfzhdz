# 达人撮合小程序 · 备案期启动（绕过域名）

域名 **已暂停解析** 时，手机**不能**直连 `mofangdianai.com`。  
本方案：**小程序 → 微信云函数 → 轻量公网 IP**（带 `Host: mofangdianai.com`），数据仍在你的轻量/ECS。

备案通过后：改 `config.release.after-beian.example.js` 恢复直连域名。

---

## 前提

- 轻量/ECS **机器仍在运行**（`meoo-auth-api`、Postgres 正常）
- 安全组/防火墙 **443 仍开放**
- 本机已拉最新代码（含 `cloudfunctions/mpErpProxy`）

---

## 第一步：开通云开发（5 分钟）

1. 微信开发者工具打开 `灵祺达人撮合小程序`
2. 顶部 **云开发** → 开通环境（按量计费，用量小费用低）
3. 复制 **环境 ID**（如 `cloud1-abc123`）
4. 编辑 `utils/config.release.js`：

```javascript
MP_CLOUD_ENV: 'cloud1-你的环境ID',
```

5. 确认 `utils/mpBuild.js` 为 **`mp-20260606-beian-bypass`**

---

## 第二步：部署云函数（不必配环境变量）

1. 若轻量公网 IP 不是 `139.196.42.5`，改文件  
   `cloudfunctions/mpErpProxy/erp-target.js` 里的 `ip` / `host`。
2. 微信开发者工具 → `cloudfunctions/mpErpProxy` → 右键 **上传并部署：云端安装依赖**。
3. **不用找环境变量**（已写在 `erp-target.js`）。若你以后找到了，也可在控制台加 `ECS_ERP_IP` 覆盖。

4. 云开发控制台 → **云函数** → `mpErpProxy` → **测试**：

```json
{ "method": "GET", "path": "/api/mp-cronet-ping" }
```

应返回 `"ok": true`。若失败，在轻量执行 `curl -k -H "Host: mofangdianai.com" https://127.0.0.1/erp-api/mp-cronet-ping`。

---

## 第三步：上传体验版

1. 上传体验版，版本备注含 `beian-bypass`
2. 手机 **删除** 旧小程序 → 重扫体验码
3. 登录页应显示 **`ECS 可达(cloud-proxy)`**

### 微信后台（备案期）

- **可不配置** request 合法域名（API 不走公网域名）
- 若开发者工具报错，详情里可勾选「不校验合法域名」仅用于本地调试

### 轻量服务器确认

```bash
# admin 登录轻量
curl -sS -H "Host: mofangdianai.com" https://127.0.0.1/erp-api/meoo-erp-api-health | head -c 120
sudo systemctl status meoo-auth-api
```

---

## 备案通过后（恢复域名）

1. 恢复 `mofangdianai.com` DNS → 轻量 IP  
2. 用 `utils/config.release.after-beian.example.js` 覆盖 `config.release.js`（`MP_USE_CLOUD_PROXY: false`）  
3. 微信 request 合法域名：`https://mofangdianai.com`  
4. 重新上传体验版  

---

## 若仍想找「环境变量」（可选，非必须）

不同版本入口不一样，可逐个试：

1. **微信开发者工具** → 顶部 **云开发** → **云函数** → 点 **`mpErpProxy`** → 右侧或右键 **配置**。
2. **云开发控制台** → **云函数** → **`mpErpProxy`** → **函数配置 / 版本与配置** → **环境变量**。
3. **云开发控制台** → **设置** → **环境设置**（不是「套餐方案」）→ 向下滚动找 **环境变量**。
4. 网页 [腾讯云 CloudBase](https://console.cloud.tencent.com/tcb/env) → 选环境 `cloud1-d4g6yyypee3d656cb` → **环境变量**。

找不到也没关系，改 `erp-target.js` 后重新部署即可。

## 常见问题

**Q：云函数测试返回 `read ECONNRESET`？**  
说明云函数已跑通，但 **腾讯云 → 你轻量 443** 被对端重置（与手机 Cronet `-101` 同类）。

1. **重新部署** 最新 `mpErpProxy`（会先试 HTTPS:443，再试 HTTP:80；返回里带 `upstream` / 多段 `error`）。
2. **轻量控制台** → 防火墙 / 安全组：**入站 443、80 对 `0.0.0.0/0`**，不要只放行自家办公 IP。
3. 关闭与 Nginx 抢 **443** 的「一键 HTTPS / 面板 SSL」，只保留 Nginx。
4. 在轻量 SSH 自测：`curl -sS -k -H "Host: mofangdianai.com" https://127.0.0.1/erp-api/mp-cronet-ping` 应为 `{"ok":true,...}`。
5. 若外网 curl IP 已是 200、仅云函数失败：在 [腾讯云 CloudBase](https://console.cloud.tencent.com/tcb/scf?envId=你的环境ID) → `mpErpProxy` → **函数配置** → 确认已开 **公网访问**（无需固定出口 IP，除非你在轻量做了 IP 白名单）。
6. 仍失败：把 `erp-target.js` 里 `insecure` 改为 `true` 后重新部署试一次；或核对公网 IP 是否仍为 `139.196.42.5`。
7. **443/80 均被 reset**：轻量 **不要用 8000**（多为 Supabase，会 `401 Unauthorized`）。改用 **18780**：防火墙加 TCP 18780，按 `scripts/ecs-nginx-erp-api-18780.snippet` 配置 Nginx；`erp-target.js` 默认 `altPort: 18780`，部署云函数后再测。ECS 需 `git pull` 才有该脚本文件。

**如何判断已部署新云函数：** 失败时 JSON 里应有 `"hint": "请在轻量检查..."` 且 `error` 含多段 `→ ECONNRESET`；若只有单行 `"error":"read ECONNRESET"`，说明仍是旧代码，请重新上传部署。

**Q：云函数测试 ok，手机仍失败？**  
检查 `MP_CLOUD_ENV` 是否填对、是否重新上传体验版。

**Q：云函数报证书错误？**  
确认 `host` 与 Nginx 证书域名一致；或 `erp-target.js` 设 `insecure: true` 后重新部署（仅备案期）。

**Q：还要买 ECS 吗？**  
不必；备案期用轻量 IP + 云函数即可。
